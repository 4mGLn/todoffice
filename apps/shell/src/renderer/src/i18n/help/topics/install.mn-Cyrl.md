# TodOffice суулгах

TodOffice-ийн суулгацыг зөвхөн GitHub дахь [Releases хуудаснаас](https://github.com/4mGLn/todoffice/releases/latest) татна. Анхны хувилбар хараахан гараагүй байна. Windows нь үндсэн хувилбар, macOS болон Linux нь бета хувилбар. Багцууд нийтлэгдсэний дараа доорх зааврыг ашиглана уу.

## Төхөөрөмжид тохирох файлыг сонго

| Үйлдлийн систем                        | Шаардлага                                        | Суулгацын файл                                                                   |
| -------------------------------------- | ------------------------------------------------ | -------------------------------------------------------------------------------- |
| **Windows**                            | Windows 10 ба түүнээс шинэ, x64 эсвэл ARM64      | `TodOffice-Setup-<version>.exe`, ARM64 бол `TodOffice-Setup-<version>-arm64.exe` |
| **Mac (бета)**, Apple silicon          | macOS 12 ба түүнээс шинэ, M1 ба түүнээс шинэ чип | `TodOffice-<version>-arm64.dmg`                                                  |
| **Mac (бета)**, Intel                  | macOS 12 ба түүнээс шинэ, Intel процессор        | `TodOffice-<version>-x64.dmg`                                                    |
| **Linux (бета)**, AppImage             | x86_64                                           | `todoffice-<version>.AppImage`                                                   |
| **Linux (бета)**, Ubuntu/Debian        | x86_64                                           | `todoffice_<version>_amd64.deb`                                                  |
| **Linux (бета)**, Fedora/RHEL/openSUSE | x86_64                                           | `todoffice-<version>.x86_64.rpm`                                                 |

Mac-ийн төрлөө мэдэхийн тулд Apple цэснээс **About This Mac**-ыг нээнэ. Apple M чиптэй бол arm64, Intel процессортой бол x64 файлыг сонгоно. Файлын нэр дэх `<version>` нь нийтлэгдсэн хувилбарын дугаар.

## Windows дээр

1. Releases хуудаснаас компьютертээ тохирох Windows суулгацыг татна.
2. Татсан файлаа ажиллуулна. Гарын үсэггүй суулгацад SmartScreen анхааруулж болно. Албан ёсны эх сурвалж, хяналтын нийлбэрийг шалгасан бол **More info**, дараа нь **Run anyway** сонголтыг ашиглаж болно.
3. Суулгацын цонхны зааврыг дагана.

Суулгасны дараа TodOffice Start цэсэнд гарч, Office болон PDF файлуудыг нээх боломжтой болно. Нийтлэгдсэн PowerShell суулгагч ашиглах бол `irm https://github.com/4mGLn/todoffice/releases/latest/download/install.ps1 | iex` тушаалыг ажиллуулна.

Суулгац кодын гарын үсэггүй тул зөвхөн албан ёсны Releases хуудаснаас авсан файлыг ажиллуулна.

## Windows татаж авах эсвэл суулгахыг блоклох үед

### Edge энэ файлыг "ихэвчлэн татаж авдаггүй" гэж хэлсэн

Microsoft Defender SmartScreen олон хүн татаж авч үзээгүй файлын талаар ингэж анхааруулж байна. Microsoft-ын файлыг хадгалах заавар нь

1. Edge-ийн татаж авах жагсаалтыг нээнэ үү ( **Ctrl+J** ), файлын хажууд …-г дараад **Keep**-г сонгоно уу
2. Нээгдсэн цонхонд **Show more**, дараа нь **Keep anyway** товчийг дарна уу. Файл таны Татаж авсан файлын хавтсанд үлдэнэ

Тэр цонхонд файлыг аюулгүй гэж мэдээлэх товчлуур байдаг. Энэ нь зөвхөн Microsoft-ын тайлангийн хуудсыг ( `feedback.smartscreen.microsoft.com` ) нээдэг бөгөөд файлыг хадгалдаггүй. Тэр хуудсыг хаагаад оронд нь цонхны **Show more** дээр дарна уу

Хэрэв цонхонд **Show more** байхгүй эсвэл **Keep anyway** байхгүй бол

- Сургууль эсвэл компанийн удирддаг компьютер дээр администратор эдгээр сэрэмжлүүлгийг алгасах замаар унтрааж болно (Edge бодлого). Дараа нь тэр компьютер дээр хэн ч файлыг хадгалж чадахгүй; администратороос үүнийг суулгах эсвэл зөвшөөрөхийг хүс
- Хувилбарын хуудаснаас өөр хөтөч дээр татаж авах нь танд ижил файлыг өгөх болно
- Хэрэв татан авалт хаагдсан хэвээр байвал администратороос тусламж хүс. **Microsoft Defender SmartScreen**-г идэвхжүүлсэн хэвээр үлдээнэ үү

### "Windows таны компьютерийг хамгаалсан" цонх гарч ирнэ

Microsoft Defender SmartScreen нь гарын үсэг зураагүй суулгагчийг анх харахад энэ цонхыг харуулдаг. **More info** дарахад **Run anyway** товчлуур гарч ирнэ. Сургууль эсвэл компанийн удирддаг компьютер дээр администраторын тохиргоо нь энэ товчлуурыг нууж болно; админаас асуу

### Smart App Control үүнийг блоклодог

Windows 11-ийн Smart App Control асаалттай үед энэ нь гарын үсэг зураагүй суулгагчдыг зогсоож, **More info** замыг санал болгодоггүй. Хэрэв администратор төхөөрөмжийг удирдаж байгаа бол суулгах ямар сонголтууд байгааг тэднээс асуу. Ухаалаг програмын хяналтыг идэвхжүүлсэн хэвээр үлдээнэ үү

## Mac дээр (бета)

macOS 12 буюу түүнээс шинэ хувилбар шаардлагатай. Суулгац нь Apple Developer ID-гаар гарын үсэг зураагүй тул macOS анх удаа нээхэд зөвшөөрөл шаардаж болно.

1. DMG файлаа нээгээд `TodOffice.app`-ыг **Applications** хавтаст чирнэ.
2. Applications хавтсаас TodOffice-ийг нээнэ. Анхааруулга гарвал **Done** дарна.
3. **System Settings ▸ Privacy & Security** хэсгийг нээнэ. TodOffice-ийн дэргэдэх **Open Anyway** товчийг дараад macOS-ийн баталгаажуулах цонхонд нууц үгээ оруулна.
4. Дахин гарч ирсэн цонхонд **Open** дарна.

macOS 12 дээр **System Preferences ▸ Security & Privacy ▸ General** хэсэгт **Open Anyway** товч байна. Нэг мөрийн суулгагч нийтлэгдсэн бол macOS болон Linux дээр `curl -fsSL https://github.com/4mGLn/todoffice/releases/latest/download/install.sh | sh` тушаалыг ажиллуулж болно.

macOS аппыг гэмтсэн гэж мэдээлбэл файлаа албан ёсны Releases хуудаснаас дахин татна. Terminal дээр доорх жишээний файлын нэрийг татсан файлынхаа нэрээр солиод SHA-256 утгыг гаргана. Үүнийг Releases хуудсан дахь хяналтын нийлбэртэй тулгана.

```sh
shasum -a 256 "TodOffice-<version>-arm64.dmg"
```

Хэрэв macOS програмыг энэ Mac дээр дэмждэггүй гэж үзвэл хоёр зүйлийг шалгана уу

- Intel Mac нь Apple Silicon файлыг ( `-arm64.dmg` ) ажиллуулж чадахгүй. **About This Mac** доорх "Процессор"-ыг шалгаад суулгасан програмаа устгаад оронд нь `-x64.dmg` файлыг суулгана уу
- macOS 11 буюу түүнээс өмнөх хувилбарыг TodOffice ажиллуулах боломжгүй. **About This Mac** мөн macOS хувилбарыг харуулж байна

Мөн Mac дээр

- AI холболтын картуудад суулгах товчлуур байхгүй. Claude Code эсвэл Codex суулгахын тулд картын албан ёсны суулгах гарын авлагын холбоосыг дагана уу. Claude ширээний програм нь Claude Code биш тул Claude Code нь ширээний програм байсан ч суулгасан байх шаардлагатай
- Хөтөч дээр нэвтэрч дуусна. Хөтөч таныг код оруулахыг хүсвэл Терминал дээр өөрөө `claude auth login` эсвэл `codex login` ажиллуулна уу. [ захиалгын холболтыг](help://subscription) харна уу

## Linux (бета) дээр

- **AppImage** : үүнийг гүйцэтгэх боломжтой болгож ( `chmod +x TodOffice-<version>.AppImage` ) файлыг ажиллуул. Суулгах алхам алга
- **deb**: `sudo apt install ./todoffice_<version>_amd64.deb` ашиглан суулгана уу
- **rpm**: `sudo dnf install ./todoffice-<version>.x86_64.rpm` ашиглан суулгана уу. OpenSUSE дээр `sudo zypper install ./todoffice-<version>.x86_64.rpm` ашиглана уу

Deb болон rpm багцуудыг `/opt/TodOffice` руу суулгаж, `/usr/bin/todoffice` терминал командыг холбоно. Mac дээрх шиг AI холболтын картууд нь суулгах товчлуургүй бөгөөд нэвтрэх үед код асуухад та `claude auth login` эсвэл `codex login`-г терминал дээр ажиллуулдаг

## Шинэчлэлтүүд

- Одоогийн хувилбарт автомат шинэчлэлт байхгүй байна. Төслийн GitHub Releases хуудаснаас шинэ хувилбарыг шалгана уу
- Linux дээр ердийн багц форматаа татаж аваарай. Эхний суулгацтай ижил алхмуудыг дагана уу
- Аливаа засварыг хадгалсны дараа л баримтыг нээлттэй байлга. Шинэ суулгагчийг ажиллуулахын өмнө TodOffice-г хаа
- Хэрэв GitHub-д холбогдох боломжгүй бол суулгасан хувилбарыг ашиглах боломжтой хэвээр байна
- Тогтвортой хувилбаруудыг хамгийн сүүлийн үеийн хувилбарууд хуудаснаас олж болно. Бета хувилбарыг тусад нь жагсааж болно
- Татаж авсан суулгагчийг нээхээс өмнө файл болон түүний шалгах нийлбэрийг хувилбарын хуудастай харьцуулна уу
- Суулгах асуудлын талаар мэдээлэхийн тулд үйлдлийн систем, багцын нэр болон суулгасан хувилбараа оруулна уу. Хэрэв шинэчлэлт нь лог үүсгэсэн бол үүнийг TodOffice өгөгдлийн хавтсанд `update-log.txt` гэж нэрлэдэг. Windows дээр та хавтсыг `%APPDATA%\TodOffice` дээрээс олох боломжтой

## Таны ажиллуулж буй барилга

**Settings ▸ About** нь апп нь танд байгаа хувилбар, дагаж мөрдөж буй суваг, төсөл хаана ажиллаж байгааг мэдээлдэг. Мөн энэ программ дээр суурилсан нээлттэй эхийн төслийг нэрлэсэн

## Командын мөр үүнтэй хамт ирдэг

Суулгах бүр нь цонхны ажилладаг ижил хөдөлгүүртэй ажилладаг `todoffice` командыг илгээдэг тул файлын талаар хэзээ ч санал нийлэхгүй. `todoffice install-cli` үүнийг таны `PATH` дээр тавьдаг. Юу хийж чадахыг [ командын мөр болон](help://cli) агентуудаас харна уу
