# EPUB ᠴᠠᠬᠢᠯᠭᠠᠨ ᠨᠣᠮ

ᠡᠯᠧᠺᠲ᠋ᠷᠣᠨ ᠨᠣᠮ ᠨᠠᠶᠢᠷᠠᠭᠤᠯᠤᠭᠴᠢ ᠨᠢ ᠨᠢᠭᠡ tab ᠶᠢᠨ ᠳᠣᠲᠣᠷ᠎ᠠ ᠪᠠᠨ ECOV ᠨᠣᠮ ( `.epub` ) ᠶᠢ ᠨᠡᠭᠡᠭᠡᠨ᠎ᠡ᠃ ᠴᠢ ᠨᠣᠮ ᠢ ᠤᠩᠰᠢᠭᠰᠠᠨ ᠤ ᠳᠠᠷᠠᠭ᠎ᠠ ᠴᠠᠭᠠᠨ ᠨᠢᠭᠤᠷ ᠳᠡᠭᠡᠷ᠎ᠡ ᠤᠩᠰᠢᠭᠰᠠᠨ ᠦᠰᠦᠭ ᠢ ᠵᠠᠯᠠᠷᠠᠭᠤᠯᠤᠨ᠂ AI  ᠡᠴᠡ ᠠᠰᠠᠭᠤᠭᠰᠠᠨ ᠤ ᠳᠠᠷᠠᠭ᠎ᠠ᠂ ᠲᠡᠭᠦᠨ ᠢ ᠰᠢᠨ᠎ᠡ ETSIS ᠫᠡᠷ ᠦᠨ ᠮᠠᠲ᠋ᠧᠷᠢᠶᠠᠯ ᠪᠣᠯᠭᠠᠨ ᠣᠷᠴᠢᠭᠤᠯᠤᠨ᠎ᠠ᠃ ᠨᠢᠭᠡ ᠪᠦᠯᠦᠭ ᠦᠨ ᠺᠣᠳ᠋ ᠢ ᠵᠠᠰᠠᠵᠤ ᠳᠡᠶᠢᠯᠬᠦ ᠳᠡᠯᠭᠡᠴᠡ ᠪᠠᠶᠢᠬᠤ ᠦᠭᠡᠶ᠃

## ᠨᠣᠮ

- ᠨᠡᠭᠡᠭᠡᠬᠦ᠃ ᠨᠡᠭᠡᠭᠡᠯᠲᠡ ᠶᠢᠨ ᠶᠠᠷᠢᠯᠴᠠᠭᠠᠨ ᠤ ᠳᠣᠲᠣᠷ᠎ᠠ ᠠᠴᠠ ᠨᠢᠭᠡ `.epub` ᠮᠠᠲ᠋ᠧᠷᠢᠶᠠᠯ ᠢ ᠳᠡᠯᠭᠡᠨ ᠭᠠᠷᠭᠠᠬᠤ ᠳᠤ ᠲᠡᠭᠦᠨ ᠢ ᠴᠣᠩᠬᠣ᠂ ᠣᠷᠴᠢᠮ ᠤᠨ ᠮᠠᠲ᠋ᠧᠷᠢᠶᠠᠯ᠂ ᠭᠠᠷ ᠤᠨ ᠮᠠᠲ᠋ᠧᠷᠢᠶᠠᠯ ᠤᠨ ᠮᠣᠳᠣ ᠪᠤᠶᠤ ᠭ᠍᠍᠍᠍ᠳᠧᠯ ᠦᠨ ᠭᠠᠷᠴᠠᠭ ᠤᠨ ᠬᠦᠰᠦᠨᠦᠭᠲᠦ ᠡᠴᠡ ᠠᠪᠴᠤ ᠭᠠᠷᠭᠠᠨ᠎ᠠ᠃ Windows ᠳᠤ ᠪᠠᠰᠠ 《ᠨᠡᠭᠡᠭᠡᠬᠦ ᠪᠡᠷ ᠢᠶᠡᠨ ᠨᠡᠭᠡᠭᠡᠨ᠎ᠡ》 ᠭᠡᠰᠡᠨ ᠨᠡᠷ᠎ᠡ ᠪᠡᠷ ᠬᠠᠩᠭᠠᠨ᠎ᠠ᠃ GenOffice ᠢ ᠤᠭᠰᠠᠷᠠᠭᠰᠠᠨ ᠨᠢ ᠡᠨᠡ ᠮᠠᠲᠧᠷᠢᠶᠠᠯ ᠤᠨ ᠠᠩᠭᠢ ᠶᠢᠨ ᠵᠣᠷᠭ `.epub` ᠪᠣᠯᠭᠠᠬᠤ ᠪᠢᠰᠢ ᠃
- ᠬᠡᠷᠪᠡ ᠨᠣᠮ ᠨᠢᠭᠡᠨᠲᠡ ᠨᠡᠭᠡᠭᠡᠭ᠍ᠰᠡᠨ ᠪᠠᠢ᠌ᠪᠠᠯ tab ᠨᠢ ᠡᠮᠦᠨ᠎ᠡ ᠲᠠᠯ᠎ᠠ ᠳᠤ ᠣᠷᠣᠨ᠎ᠠ ᠃
- ᠬᠠᠭᠤᠴᠢᠨ ᠤ ᠬᠠᠮᠠᠭᠠᠯᠠᠯᠲᠠ ᠲᠠᠢ （ DRM ） ᠨᠣᠮ ᠳᠡᠪᠲᠡᠷ ᠢ ᠨᠡᠭᠡᠭᠡᠵᠦ ᠪᠣᠯᠬᠤ ᠦᠭᠡᠢ ᠄ ᠲᠠᠨ ᠤ ᠬᠤᠳᠠᠯᠳᠤᠨ ᠠᠪᠤᠭᠰᠠᠨ ᠳᠡᠯᠭᠡᠭᠦᠷ ᠦᠨ app ᠳᠣᠲᠣᠷ᠎ᠠ ᠨᠡᠭᠡᠭᠡᠵᠦ ᠪᠣᠯᠣᠨ᠎ᠠ ᠃ ᠡᠪᠳᠡᠭᠰᠡᠨ ᠳᠠᠩᠰᠠ ᠡᠪᠬᠡᠮᠡᠯ ᠪᠠ Eᠲᠦ ᠳᠡᠪᠲᠡᠷ ᠨᠣᠮ ᠤᠨ ᠪᠢᠰᠢ ᠶᠢ ᠴᠤ ᠨᠡᠭᠡᠭᠡᠵᠦ ᠪᠣᠯᠬᠤ ᠦᠭᠡᠢ ᠂ ᠡᠭᠦᠨ ᠦ ᠰᠢᠯᠲᠠᠭᠠᠨ ᠢ ᠨᠢ ᠲᠣᠳᠣᠷᠬᠠᠢ ᠬᠡᠯᠡᠵᠦ ᠥᠭ᠍ᠬᠦ ᠶᠤᠮ ᠃
- **ᠲᠤᠭᠲᠠᠩᠭᠤᠢ ᠪᠠᠷ ᠵᠣᠬᠢᠶᠠᠭᠰᠠᠨ ᠨᠣᠮ ᠪᠢᠴᠢᠭ᠌** ( ᠵᠢᠷᠤᠭ ᠳᠡᠪᠲᠡᠷ ᠂ ᠵᠢᠷᠤᠭᠲᠤ ᠨᠣᠮ ᠂ ᠵᠢᠷᠤᠭ ᠤᠨ ᠵᠢᠷᠤᠭ ᠬᠦᠰᠦᠨᠦᠭ᠍ ) ᠢ ᠵᠦᠪᠬᠡᠨ ᠤᠩᠰᠢᠬᠤ ᠳᠤ ᠨᠡᠭᠡᠭᠡᠨ᠎ᠡ ᠃ ᠵᠠᠰᠠᠭᠤᠯᠬᠤ ᠂ AI ᠵᠠᠰᠠᠬᠤ᠂ ᠰᠣᠯᠢᠬᠤ ᠂ ᠣᠷᠴᠢᠭᠤᠯᠬᠤ ᠶᠢ ᠲᠠᠰᠤᠯᠵᠤ ᠂ ᠪᠠᠶᠢᠳᠠᠯ ᠤᠨ ᠱᠤᠭᠤᠮ ᠨᠢ ᠶᠠᠭᠤᠨ ᠤ ᠤᠴᠢᠷ ᠠᠴᠠ ᠲᠠᠶᠢᠯᠪᠤᠷᠢᠯᠠᠵᠠᠢ ᠃ AI ᠤᠩᠰᠢᠬᠤ ᠪᠠ ᠠᠰᠠᠭᠤᠬᠤ ᠨᠢ ᠮᠥᠨ ᠠᠵᠢᠯᠯᠠᠨ᠎ᠠ ᠃
- ᠳᠠᠩᠰᠠ ᠡᠪᠬᠡᠮᠡᠯ ᠨᠢ ᠬᠡᠪ ᠢᠶᠡᠷ ᠢᠶᠡᠨ ᠢᠯᠡᠭᠦᠬᠡᠨ ᠪᠠᠢ᠌ᠳᠠᠯ ᠢ ᠠᠯᠢ ᠴᠢᠳᠠᠬᠤ ᠪᠠᠷ ᠰᠠᠢ᠌ᠬᠠᠨ ᠲᠠᠯᠪᠢᠵᠠᠢ ᠂ ᠭᠡᠪᠡᠴᠦ ᠵᠠᠰᠠᠵᠤ ᠦᠵᠡᠵᠦ ᠪᠣᠯᠬᠤ ᠦᠭᠡᠢ ᠂ ᠳᠡᠭᠡᠷ᠎ᠡ ᠲᠠᠯ᠎ᠠ ᠳᠤᠨᠢ ᠲᠡᠮᠲᠡᠭᠯᠡᠯ ᠨᠢ ᠡᠭᠦᠨ ᠢ ᠲᠣᠳᠣᠷᠬᠠᠢ᠌ᠯᠠᠵᠤ ᠪᠠᠢ᠌ᠨ᠎ᠠ ᠃ ᠲᠡᠭᠦᠨ ᠢ ᠬᠠᠳᠠᠭᠠᠯᠠᠬᠤ ᠭᠡᠰᠡᠨ ᠦᠭᠡᠢ ᠪᠡᠷ ᠣᠷᠴᠢᠭᠤᠯᠤᠯᠲᠠ ᠶᠢᠨ ᠬᠡᠯᠪᠡᠷᠢ ᠪᠡᠷ ᠤᠭ ᠬᠡᠯᠡ ᠪᠡᠷ ᠨᠢ ᠦᠯᠡᠳᠡᠭᠡᠨ᠎ᠡ ᠃

## ᠤᠩᠰᠢᠬᠤ

- The **Contents** pane on the left shows the book's table of contents. Click an entry to go there. A book without one gets a list of its chapters. Drag the pane's inner edge to change its width; double-click the edge to go back to the original width. The find pane uses the same width.
- Each chapter scrolls up and down. Keep scrolling past the end of a chapter to go to the next one, or past its start to go back. The status line shows which chapter you are in.
- The **View** tab changes the text size and line spacing and switches **Dark view** on and off. These settings change only the screen, never the book, and apply to every book.
- The place where you stopped reading is remembered for each file, in the app's data folder and not in the book.
- **Find in book** ( Ctrl+F ) searches every chapter. Click a result to go to it.
- A link inside the book moves to that place. Web and email links open in your default browser; other addresses are not opened.
- The book's own scripts never run and nothing is loaded from the internet. Sound and video do not play.
