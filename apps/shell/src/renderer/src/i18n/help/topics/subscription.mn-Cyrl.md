# Захиалгаа холбох

TodOffice-ийн AI-г өөрийн Claude (Anthropic) эсвэл ChatGPT (OpenAI) захиалгаар ашиглаж болно. ChatGPT-ийг TodOffice-д шууд эсвэл энэ компьютерт суулгасан Codex програмаар холбоно. API түлхүүр болон TodOffice-ийн тусдаа бүртгэл шаардахгүй.

## Энэ нь хэрхэн ажилладаг

- Claude ашиглахад TodOffice энэ компьютерт суулгасан **Claude Code** программаар хүсэлтийг гүйцэтгүүлнэ. Хүсэлт таны тухайн программд нэвтэрсэн бүртгэлийн захиалгын лимитэд тооцогдоно.
- ChatGPT-ийг компьютерт тусдаа программ суулгалгүйгээр TodOffice-д шууд холбоно. Хөтөч дээр нээгдсэн OpenAI-ийн хуудсанд нэвтэрч, аппад ChatGPT захиалгыг ашиглах зөвшөөрөл өгнө. Хүсэлт энэ компьютерээс OpenAI руу шууд очиж, таны захиалгын лимитэд тооцогдоно.
- **Codex** бол OpenAI-ийн программ. ChatGPT-ийг Codex-оор холбосон бол TodOffice хүсэлтийг Claude Code-той адил тухайн программаар гүйцэтгүүлнэ.
- TodOffice дотроо нэвтрэх маягтгүй. Үйлчилгээ үзүүлэгчийн албан ёсны программ эсвэл хөтчөөр нээгдсэн хуудсанд нэвтэрнэ. TodOffice Claude Code болон Codex-ийн нэвтрэх мэдээллийг уншихгүй, хадгалахгүй. ChatGPT-ийг шууд холбоход OpenAI-аас энэ аппад олгосон нэвтрэх мэдээллийг л компьютерт хадгална. Windows дээр шифрлэн хадгална. TodOffice таны ChatGPT нууц үгийг харахгүй.

## Эхлэхээсээ өмнө

Танд эдгээрийн аль нэг нь хэрэгтэй. Аль аль нь байвал зүгээр.

- Клаудын захиалга (Pro эсвэл Макс төлөвлөгөө; үнэгүй Клод данс холбогдож чадахгүй), Клод Кодын програмыг энэ компьютер дээр суулгаж, нэвтэрсэн.
- ChatGPT төлөвлөгөө. Шууд холбогдсон тул суулгах програм алга. Үнэгүй төлөвлөгөө нь зөвхөн бага зэрэг ашиглах боломжийг олгодог. Хэрэв та энэ компьютер дээр Codex програмыг аль хэдийн ашиглаж байгаа бол Codex-ээр холбогдож болно.

Хэрэв Claude Code эсвэл Codex суулгаагүй эсвэл нэвтэрч амжаагүй бол дараагийн хэсгийн товчлуурууд үүнийг зохицуулна.

1. Нүүр хуудасны зүүн доод талд байгаа эгнээнээс **тохиргоог**-г нээгээд **AI**-г сонгоно уу. **захиалгын холболтын** дор Claude, ChatGPT болон Codex-д зориулсан картууд байгаа. ChatGPT төлөвлөгөөний тусламжтайгаар ChatGPT картаар холбогдоно уу. Codex карт нь энэ компьютер дээр Codex програмыг ашигладаг хүмүүст зориулагдсан.
2. Карт дээр юу бичсэнийг уншаад товчлуурыг нь дар. Доорх хүснэгтэд муж бүрийг тайлбарласан болно.
3. GenOffice цонх руу буцна уу. Карт өөрөө дахин шалгадаг ба **дахин шалгадаг** нэг дор шалгана.

Эхний эхлүүлэх үед угтан авах дэлгэцийн AI холболтын алхам, хиймэл оюун ухаан холбогдоогүй үед AI самбар эхлээд "Та аль хиймэл хиймэл оюун ухаанаа ашиглаж байна вэ?" Клаудын төлбөртэй захиалга, ChatGPT эсвэл аль нэгийг нь сонгоорой, та зөвхөн энэ замын алхмууд болон түүний нэг картыг харах болно. Клодын хувьд програмыг суулгах → нэвтрэх → холбогдох алхамууд; ChatGPT-ийн хувьд нэвтэрнэ үү → холбогдсон. ChatGPT замын дагуу **энэ компьютер дээр Codex программыг аль хэдийн ашиглаж байна уу? Codex**-тай холбогдож Codex зам руу шилждэг (програмыг суулгана уу → нэвтэрнэ үү → холбогдсон байна) ба **тухайн зам дээр Codex** байхгүй бол шууд аппликешнд холбогдох нь таныг шууд холболт руу буцаана. Хэрэв Codex аль хэдийн холбогдсон бол Codex замыг эхнээс нь харуулна. **Өөр арга сонгоно уу** танд дахин сонгох боломжийг олгох бөгөөд та бүгдийг алгасаад дараа нь холбогдох боломжтой. ## Захиалгагүйгээр: үнэгүй AI

Клауд эсвэл ChatGPT захиалга байхгүй юу? Тохиргооны доор ▸ AI, **Үнэгүй ашиглаарай** оронд нь үнэгүй AI-г холбодог. Сонгож байна **Аль нь ч биш** тавтай морилно уу дэлгэцийн AI холболтын алхамд ижил картуудыг харуулдаг бөгөөд юу ч холбогдоогүй үед AI самбар дээр үүнийг сонгох нь санал болгодог. **Үнэгүй AI-г холбоно уу** .

- **OpenRouter**: **товчийг дарж** хөтөч дээр холбогдоно уу. Таны хөтөч OpenRouter-ийг нээнэ; бүртгүүлэх эсвэл нэвтэрч, нэвтрэхийг зөвшөөрнө үү. Хөтөч холбогдсон гэж хэлэхэд tab-г хаагаад буцаж ирээрэй. Хуулбарлах түлхүүр байхгүй бөгөөд өнөөдөр хичнээн үнэгүй хүсэлт үлдсэнийг карт харуулдаг.
- **Google Gemini** : **товчийг дарж** түлхүүр авч, Google AI Studio дээр түлхүүр хийж, картанд оруулаад **Connect** дээр дарна уу. Зөвхөн 18 ба түүнээс дээш насны хүмүүст зориулагдсан. Төлбөрийг асаасан Google төсөлд хийсэн түлхүүрийг цэнэглэх боломжтой.
- Холбогдсоны дараа тэр хиймэл оюун ухаан нь **AI болж**-г ашиглах болно. Хоёулаа холбогдсон үед **Энэ AI** картыг хооронд нь сольж ашиглах. **салгах** GenOffice-аас түлхүүрийг устгана.

## Хэрэглээгээр тооцдог холболт

Карт дээр **Signed in, but not with a subscription** гэж байвал захиалгагүй бүртгэлээр нэвтэрсэн байна. Ашиглалтын хэмжээгээр төлбөр тооцно.

- **Use anyway** товчийг дарж зөвшөөрөх хүртэл TodOffice уг холболтыг ашиглахгүй. Ашиглах хүсэлт бүрийн төлбөр тухайн бүртгэлд тооцогдоно.
- Зөвшөөрсөн ч автоматаар сонгохгүй. **AI to use** хэсэгт **Paid** гэж тэмдэглэгдсэн уг холболтыг өөрөө сонгоно.
- Зөвшөөрөл зөвхөн тухайн программд үйлчилнэ. Программаас гарах эсвэл бүртгэл солигдоход зөвшөөрлийг цуцална.
- Захиалгаа ашиглахын тулд тухайн программд захиалгатай бүртгэлээрээ нэвтэрч **Check again** товчийг дарна.

- **Өөр бүртгэлээр нэвтэрнэ үү** програмын өөрийн нэвтрэлтийг дахин эхлүүлнэ. Үүнийг нээгдэх цонхонд нөгөө дансаар дуусгана уу.
- **Гарах** нь програмаас гарах үйлдлийг ажиллуулдаг. Дараа нь карт дээр **Not signed in**-д гарын үсэг зураагүй гэж бичнэ.
- Claude болон Codex картууд дээр хоёулаа зөвхөн GenOffice-д биш энэ бүх компьютер дээрх програмд хамаарна. Хэрэв та Claude Code эсвэл Codex-ийг терминалдаа бас ашигладаг бол энэ нь тэндээс гарсан эсвэл өөр данс руу шилжсэн байна. GenOffice эхлээд баталгаажуулахыг танаас хүсч байна.
- Claude болон Codex картууд нь мөн **-тай. Энэ аппликешнд бүү ашигла**. Энэ нь програм болон нэвтрэлтийг байгаагаар нь орхиж, зөвхөн GenOffice-г ашиглахыг зогсооно: статус шалгахгүй, хүсэлт гаргахгүй, **автоматаар** түүн дээр дамждаггүй. Хөтөлбөрийг ашигладаг терминал нөлөөлөхгүй. Дараа нь карт энэ аппликейшн дээр **Off гэж бичээд** гэж бичээд **Дахин ашиглах** үүнийг буцааж асаана. GenOffice-аас гадна юу ч өөрчлөгддөггүй тул аль аль нь таныг баталгаажуулахыг шаарддаггүй.
- ChatGPT карт нь өөр. **Гарах** "Энэ нь ChatGPT-г энэ апп-аас салгаж байна" гэж баталгаажуулахыг хүссэн; Таныг баталгаажуулсны дараа GenOffice OpenAI-аас энэ програмын холболтыг таслахыг хүсч, энэ компьютер дээр хадгалагдсан нэвтрэх эрхийг устгана. **Өөр акаунтаар нэвтэрнэ үү** таны хөтчөөс асуухгүйгээр шууд нэвтрэх хуудсыг нээнэ. Энэ компьютер дээрх бусад программуудад аль аль нь нөлөөлөхгүй, Codex багтсан.
- Холбогдсон ChatGPT карт нь "Энэ апп-н хиймэл оюун ухаан таны ChatGPT төлөвлөгөөнд ажилладаг" гэсэн бөгөөд **Хэрэглээг удирдах** холбоостой. Энэ нь таны ChatGPT тохиргооны ашиглалтын хуудсыг нээж, энэ програмыг хэр их ашиглаж байгааг харж, зөвхөн энэ аппликешнд хязгаарлалт тавих боломжтой.
- Бүртгэл болон эдгээр хоёр товчлуур нь зөвхөн энд, Тохиргоо ▸ AI хэсэгт харагдана. GenOffice дансыг харуулдаг бөгөөд хаана ч хадгалдаггүй.

## Ашиглах AI-г сонгох

Settings ▸ AI хэсгийн **AI to use** анх **Automatic** горимтой байна. Автомат горимд дараах дарааллаар сонгоно.

1. Claude карт **Connected** бол Claude-ийг сонгоно.
2. Үгүй бол ChatGPT карт **Connected** үед ChatGPT-ийг сонгоно.
3. Үгүй бол Codex карт **Connected** үед Codex-ийг сонгоно.
4. Холбогдсон үйлчилгээ байхгүй бол AI самбар холбогдох зааврыг харуулна.

**Automatic** горим нь API түлхүүр болон хэрэглээгээр төлбөр тооцдог холболтыг автоматаар сонгодоггүй. Тэдгээрийг зөвхөн та өөрөө сонгосон үед ашиглана.

Эндээс эсвэл AI самбарын доод хэсгийн загварын жагсаалтаас AI-г өөрөө сонгож болно. Сонгосон холболт ажиллахаа болиход TodOffice өөр холболт руу автоматаар шилжихгүй. Шалтгаан, дахин холбогдох аргыг харуулна.

Загварын жагсаалт нь программын өөрөө мэдээлдэг загваруудыг харуулдаг (ChatGPT-ийн хувьд OpenAI-ийн хэлснээр таны төлөвлөгөөнд ашиглах боломжтой загварууд; тэдгээрийн эхнийх нь нэгийг сонгох хүртэл ашиглагдана): тус бүрийг нэрээр нь, яг загварын ID-г нь хажууд нь, мөн **Өгөгдмөл загвар** нь одоогийн байгаа загвартай. AI самбарын доод талд байрлах чип ба **AI нь**-г ашиглахад энэ загварыг мөн нэрлэсэн. Жагсаалтыг уншихад хиймэл оюун ухаанаас юу ч асуухгүй тул таны төлөвлөгөөнд нөлөөлөхгүй. Хэрэв програм нь загвараа мэдээлэхэд хэтэрхий хуучирсан бол оронд нь богино хэмжээний жагсаалт гарч ирнэ.

Codex-ийг сонгох боломжтой газар бүрт "Програм дотор Codex захиалгыг ашиглах нь OpenAI-аас албан ёсоор санал болгосон арга биш" гэсэн нэг мөр харагдана. Үүнийг бодолцож шийдээрэй.

## Хүсэлт зогссон үед

Төлөвлөгөөний хязгаар дууссан, нэвтрэх хугацаа дууссан эсвэл програм байхгүй болсон үед хүсэлт зогсдог. GenOffice нь өөрөө өөр хиймэл оюун ухаан руу шилжихгүй.

- Хариулт хаана зогссон шалтгааныг харуулав. Ашигласан хязгаарын хувьд програм үүнийг мэдээлэх үед дахин тохируулах хугацааг мөн харуулна.
- ChatGPT таны багцын хязгаар эсвэл ChatGPT тохиргоондоо энэ апп-д тохируулсан хязгаар дууссан үед шууд зогсдог. Дахин тохируулах цаг харагдахгүй байна. Хэрэв та ChatGPT тохиргоондоо энэ програмыг салгасан бол карт **болж хувирна**-д нэвтрээгүй; дахин нэвтэрнэ үү.
- Хэрэв таны бусад захиалга холбогдсон бол a **Үргэлжлүүлэх …** товчлуур гарч ирнэ, жишээ нь **ChatGPT-р үргэлжлүүлнэ үү** эсвэл **Codex-ийг үргэлжлүүлнэ үү** Үүнийг дарснаар AI-г ашиглах боломжтой болгож, загварын жагсаалт нь өөрчлөлтийг харуулж, хүсэлтийг дахин ажиллуулна.
- Хэрэв таны зөвшөөрөгдсөн цорын ганц холболт бол төлбөр төлж нэвтрэх юм бол ижил товчлуур нь зардлын тухай тэмдэглэлтэй ирдэг.
- Таныг API түлхүүр рүү шилжүүлэх товчлуур хэзээ ч байдаггүй.

## Хэрэглээний шугам

Хязгаарлалтын 80% ба түүнээс дээш хувийг ашигласны дараа AI самбарт "85% ашигласан · 15:00 цагт дахин тохируулна" гэх мэт мөр гарч ирнэ. Клод 5 цагийн хязгаар болон 7 хоногийн хязгаарыг мэдээлдэг бөгөөд Codex нь тэдгээрийг мэдээлэхдээ ижил байдлаар харагдана. 80% -иас доош буюу програм юу ч мэдээлэхгүй бол ямар ч мөр харагдахгүй. Шууд холбогдсон ChatGPT ийм шугамыг харуулдаггүй; ChatGPT карт дээрх **ашиглалтыг удирдах**-ээр дамжуулан юу ашигласан болохыг харна уу.

## Ямар мэдээлэл хаашаа дамжих вэ

Захиалга анх ашиглах боломжтой болоход TodOffice мэдэгдэл харуулна. Дахин уншихдаа Settings ▸ AI хэсгийн **First-connection notice**-оос **View again** дарна.

- Баримтын агуулга болон харилцан яриаг таны бүртгэлээр Anthropic эсвэл OpenAI руу илгээнэ.
- Тэр агуулгыг AI загвар сургахад ашиглах эсэх нь тус компанийн бүртгэл дэх таны тохиргооноос хамаарна.
- TodOffice нь Codex-ийн харилцан ярианы түүх хадгалах тохиргоог унтраана. Codex өөрийн оношилгооны тэмдэглэлээ компьютерт хадгалж болно.

ChatGPT-ийг шууд холбосон бол хүсэлт Codex-оор дамжихгүй. Энэ компьютерээс OpenAI руу шууд очно.

Аль AI-г ашигласнаас үл хамааран **Hide the selection from AI** үйлдлээр нуусан хэсгийг илгээхгүй.

## Мэдэх сайхан байна

- **хурд.** Клод код эсвэл Codex-ээр дамжуулан хариу өгөх нь API түлхүүрээр дамжуулан нэг секундээс хэдхэн секундын дараа эхэлдэг, учир нь програм эхлээд эхлэх ёстой. ChatGPT шууд холбогдож ямар ч програм эхлүүлдэггүй.
- **Үнэгүй ChatGPT төлөвлөгөө.** Энэ нь Холбогдсон гэж харагдах боловч хязгаар нь бага тул хүсэлтүүд хурдан зогсдог. Хэрэглээний шугам нь түүнд харагдахгүй байна.
- **Зураг үүсгэх.** Та ямар ч хиймэл оюун ухаантай чатлахаас үл хамааран зургийг Codex програмаар дамжуулан таны ChatGPT төлөвлөгөөний (Plus буюу түүнээс дээш) дагуу хийж, тухайн төлөвлөгөөний төлбөрийг төлнө. Үнэгүй төлөвлөгөөнд зургийн хэрэгсэл байхгүй тул боломжгүй. Шууд холбогдсон ChatGPT зураг хийх боломжгүй, учир нь OpenAI үүнийг зөвшөөрдөггүй; ChatGPT төлөвлөгөөгөө зураг дээр ашиглахын тулд Codex програмыг ижил ChatGPT бүртгэлээр холбоно уу. Зурганд ашиглалтын төлбөртэй нэвтрэх эрхийг ашиглахгүй. [AI загвар болон тохиргоог](help://ai-models) харна уу.
- **прокси.** Claude Code болон Codex нь GenOffice-аас прокси тохиргоог авдаггүй. Тэд энэ компьютерт зориулсан прокси багцыг, жишээ нь `HTTPS_PROXY` орчны хувьсагчийг терминал дээр ажиллуулдаг шиг ашигладаг. Хэрэв тэд терминалд холбогдож чадахгүй бол эндээс ч холбогдож чадахгүй.
- **тушаалууд болон бусад програмууд.** `ieumoffice` тушаал эсвэл холбогдсон кодлогч агентаас ирсэн хүсэлт нь таныг зөвшөөрөхгүй бол таны захиалгыг ашиглахгүй. Тэгээд ч энэ нь Claude Code эсвэл Codex ашигладаг бөгөөд хэзээ ч ChatGPT шууд холбогддоггүй. [Кодлох агентыг холбох](help://mcp)-г үзнэ үү.
- **Агент горим.** [Агент горим](help://agent-mode) энэ компьютер дээр Claude Code эсвэл Codex-ийг ажиллуулдаг. Шууд холбогдсон ChatGPT агентийг ажиллуулж чадахгүй.
