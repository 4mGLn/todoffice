- **On empty canvas** ᠄ ᠰᠢᠨ᠎ᠡ ᠰᠠᠨᠭᠭᠤᠯᠲᠠ （ ᠪᠠᠶᠢᠷᠢᠰᠢᠯᠲᠠ ᠶᠢ ᠰᠣᠩᠭᠣᠵᠤ ᠪᠣᠯᠬᠤ） ᠂ ᠰᠠᠯᠠᠭᠠᠨ **paste as picture** ᠪᠠᠭᠤᠯᠭᠠᠬᠤ ᠂ ᠬᠠᠪᠴᠢᠬᠤ （ ᠪᠠᠰᠠ **paste keeping source formatting** ） ᠂ ᠬᠠᠪᠲᠠᠰᠤ ᠶᠢ ᠳᠠᠬᠢᠨ ᠳᠠᠪᠲᠠᠨ ᠬᠢᠬᠦ / ᠬᠠᠰᠤᠬᠤ ᠪᠤᠶᠤ ᠨᠢᠭᠤᠬᠤ ᠂ **add section** ( ᠡᠮᠦᠨ᠎ᠡ ) ᠂ ᠬᠡᠰᠡᠭ ᠦᠨ ᠨᠡᠷᠡᠶᠢᠳᠦᠯ ᠢ ᠥᠭᠡᠷᠡᠴᠢᠯᠡᠬᠦ / ᠳᠡᠭᠡᠭ᠍ᠰᠢ ᠳᠡᠭᠡᠭ᠍ᠰᠢ ᠰᠢᠯᠵᠢᠭᠦᠯᠬᠦ / ᠪᠠᠭᠤᠯᠭᠠᠬᠤ / ᠲᠠᠲᠠᠬᠤ ᠪᠥᠬᠥᠨ ᠢ ᠥᠷᠭᠡᠳᠬᠡᠬᠦ ᠂ **format background** / **change background image** ᠂ ᠨᠢᠭᠤᠳᠠᠨ ᠤ ᠪᠠᠢ᠌ᠷᠢᠰᠢᠯ ᠢ ᠳᠠᠬᠢᠨ ᠲᠣᠭᠲᠠᠭᠠᠬᠤ
- **ᠰᠤᠩᠭ᠋ᠤᠭᠰᠠᠨ ᠡᠯᠧᠮᠧᠨ᠋ᠲ** ᠳᠡᠭᠡᠷ᠎ᠡ ᠄ ᠦᠰᠦᠭ ᠢᠶᠡᠨ ᠵᠠᠰᠠᠨ ᠵᠠᠰᠠᠬᠤ᠂ ᠬᠡᠰᠡᠭᠲᠦ ᠬᠣᠯᠪᠣᠭᠠᠰᠤ ᠂ ᠶᠡᠬᠡ ᠪᠠᠭ᠎ᠠ ᠶᠢᠨ ᠪᠠᠶᠢᠷᠢ ᠂ **align** ᠶᠢ ᠨᠢᠭᠡᠳᠬᠡᠬᠦ （ᠵᠡᠭᠦᠨ ᠳᠤᠮᠳᠠ ᠪᠠᠷᠠᠭᠤᠨ ᠤ ᠣᠷᠣᠢ ᠶᠢᠨ ᠳᠣᠣᠷᠠᠳᠤ ᠱᠤᠭᠤᠮ ᠂ ᠬᠦᠨᠲᠡ ᠪᠡᠷ ᠬᠤᠪᠢᠶᠠᠵᠤ ᠂ ᠡᠮᠦᠨ᠎ᠡ ᠪᠡᠨ ᠭᠠᠷᠭᠠᠬᠤ / ᠠᠷᠤ ᠤᠷᠤᠭᠤ ᠶᠠᠪᠤᠭᠤᠯᠬᠤ ᠂ ᠪᠦᠯᠬᠦᠮ ᠢ ᠨᠢ ᠪᠠᠭᠤᠯᠭᠠᠬᠤ ᠪᠤᠶᠤ ᠪᠦᠯᠬᠦᠮ ᠂ ᠬᠦᠨᠲᠡᠯᠡᠨ ᠤᠷᠪᠠᠭᠤᠯᠬᠤ ᠂ ᠵᠢᠷᠤᠭ ᠦᠵᠡᠯ ᠢ ᠬᠠᠰᠤᠬᠤ** ᠣᠷᠣᠯᠠᠭᠤᠯᠬᠤ ᠂ ᠵᠢᠷᠤᠭ ᠪᠣᠯᠭᠠᠨ ᠬᠠᠳᠠᠭᠠᠯᠠᠬᠤ ᠂ ᠶᠠᠩᠵᠤ ᠪᠠᠨ ᠥᠭᠡᠷᠡᠴᠢᠯᠡᠬᠦ ** ᠪᠡᠨ ᠲᠣᠭᠲᠠᠭᠰᠠᠨ ᠬᠡᠯᠪᠡᠷᠢ ᠳᠦᠷᠰᠦ ᠂ ᠵᠠᠰᠠᠭᠤᠯᠬᠤ ᠴᠡᠭ ᠦᠨ ᠵᠢᠭᠠᠯᠲᠠ ᠪᠣᠯᠭᠠᠨ᠎ᠠ ᠃ ᠦᠰᠦᠭ ᠦᠨ ᠡᠯᠧᠮᠧᠨ᠋ᠲ ᠨᠢ ᠪᠠᠰᠠ ᠠᠯᠠᠭ᠎ᠠ / ᠲᠣᠰᠣᠭᠠᠯ / ᠲᠣᠰᠣᠭᠠᠯ / ᠲᠣᠰᠣᠭᠠᠯ ᠲᠣᠰᠣᠭᠠᠯ ᠪᠤᠶᠤ ᠳ᠋ᠤᠭᠠᠷᠯᠠᠬᠤ ᠪᠣᠯᠣᠨ᠎ᠠ ᠃
- **ᠰᠤᠩᠭ᠋ᠤᠭᠰᠠᠨ ᠨᠢᠭᠡ** ᠳᠡᠭᠡᠷ᠎ᠡ ᠄ ᠮᠥᠷ / ᠪᠤᠯᠤᠩ ᠢ ᠬᠠᠪᠴᠢᠬᠤ （ ᠳᠡᠭᠡᠳᠦ / ᠳᠣᠤᠷ᠎ᠠ / ᠵᠡᠭᠦᠨ / ᠪᠠᠷᠠᠭᠤᠨ ） ᠂ ᠡᠩᠨᠡᠭᠡᠨ ᠦ ᠮᠥᠷ / ᠪᠤᠯᠤᠩ ᠢ ᠬᠠᠰᠤᠬᠤ ᠂ ᠪᠠᠷᠠᠭᠤᠨ ᠢ ᠨᠡᠶᠢᠯᠡᠭᠦᠯᠬᠦ / ᠳᠣᠷᠣᠭᠰᠢ ᠨᠡᠶᠢᠯᠡᠭᠦᠯᠬᠦ ᠂ ᠡᠰ ᠢ ᠰᠠᠯᠭᠠᠬᠤ ᠂ **ᠢ ᠰᠡᠭᠦᠳᠡᠷᠯᠡᠬᠦ** ᠂ ᠡᠨᠡᠳᠭᠡ ᠶᠢᠨ ᠠᠭᠤᠯᠭ᠎ᠠ ᠶᠢ ᠲᠣᠪᠴᠢᠯᠠᠬᠤ （ ᠳᠡᠭᠡᠳᠦ ᠦᠨ᠎ᠡ ᠶᠢᠨ ᠳᠣᠣᠷ᠎ᠠ ） ᠃
