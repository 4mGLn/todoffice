# Файлын үйлдлүүд

Энэ бүлэгт засварлагч бүрийн хуваалцсан файлын үйлдлүүдийг багтаасан болно; редактор бүрийн өөрийн экспортын сонголтууд нь түүний бүлэгт байдаг.

Мөрийн **⋯ цэс** (файлын мөр дээр хулганаа аваачих) нь дараах үйлдлүүдийг цуглуулдаг:

![A file row's ⋯ menu](img/file-ops.png)

## Нэрээ өөрчлөх

Хоёр нэвтрэх цэг, нэг багц шалгалт:

- Нүүр хуудасны мөр **⋯ ▸** нэрийг өөрчил.
- **tab** файл дээр давхар товшино уу ([Таб болон цонхны менежмент](help://tabs-and-windows) хэсгийг үзнэ үү).

Дүрэм: өргөтгөл автоматаар хадгалагдана; хууль бус тэмдэгтүүд, арын цэгүүд болон нөөцлөгдсөн нэрс (CON/NUL болон найзууд) мессежээр татгалзсан; ижил фолдерын нэрний зөрчил мөн блоклогдсон. Диск дээрх жинхэнэ файлын нэрийг өөрчилсөн бөгөөд дараа нь сүүлийн үеийн файлууд болон одууд орно.

## Устгах

- Нүүр хуудас **⋯ ▸** устгах : ямар файлуудыг асууж, дараа нь тэдгээрийг **системийн хогийн сав** руу зөөж, үйлдлийн систем нь сэргээх боломжтой. GenOffice үүнийг буцаах арга хэмжээ авдаггүй - нөхөн сэргээх нь шарсан талх биш хогийн савны ажил юм.

## Давхардсан

**⋯ ▸ Давхардсан** нь нэг хавтсанд <нэр> хуулбар үүсгэдэг; мөргөлдөөн автоматаар тоолуур нэмнэ. Хуулбар нь танд нээгдэхээс илүүтэй **Саяхан** дээр нэмэгдсэн тул таны өмнө биш нэг товшилтын зайд байх болно.

## Хадгалах ба Save As

- **⌘S / ctrl+S** одоогийн файлыг хадгалдаг; Гарчиггүй файл эхлээд байршил, нэрийг асууна.
- Ихэнх засварлагчдад Save As харилцах цонхон дээрх файлын төрлийн жагсаалт нь экспортын форматыг (PDF, зураг, бусад баримт бичгийн формат) санал болгодог. Тэдгээрийн аль нэгийг нь сонгосноор зөвхөн хуулбарыг бичнэ; нээлттэй баримт бичиг болон түүний tab эх файл дээр үлдэнэ. Хэд хэдэн хуудасны зургийг `name-01.png`, `name-02.png`, … гэж хуваасан.
- **Docs** : Save As жагсаалт нь .hwp болон .hwpx-г санал болгодог (Файл ▸ HWP баримтаар экспортлох… мөн адил). Сэтгэгдэл, тэгшитгэл эсвэл текст хайрцаг зэрэг ямар нэг зүйлийг шилжүүлэх боломжгүй бол файлыг бичихээс өмнө танд мэдэгдэнэ.
- **Save As** шинэ файл бичих ба эх хувийг хөндөөгүй; дараагийн засварууд нь шинэ файлд чиглэгддэг.
- Хадгалах бүр нь атом (түр файл + нэрийг өөрчлөх); Дунд бичихээс гарах нь файлыг гэмтээж чадахгүй.
- Автоматаар хадгалах нь засварлагч бүрийн шилжилтийг дагадаг; Өөрийн гэсэн файлгүй шинэ баримт бичиг анхны хадгалагдсаны дараа эхэлдэг ([Хурдан эхлүүлэх](help://getting-started)-г үзнэ үү).

## PDF руу экспортлох

- руу экспортлох. **Docs** : Файл ▸ Хуудасны дагуу PDF (эсвэл туузан товчлуур) болгон экспортлох.
- **Слайд** : том тавцангийн хувьд ахиц дэвшилтэй, хуудас бүрээр нь растер болгож экспортлох.
- **Хуудас** : хэвлэх хуудасны дараа экспорт хийнэ.
- Экспортыг далд цонхонд үзүүлж, сонгосон газар бүртээ буулгана.

## Word / зураг руу экспортлох

- **PDF ▸ Word руу хөрвүүлэх** : PDF-г .docx болгон хувиргах (орон нутгийн хэмжээнд хөрвүүлсэн; нарийн төвөгтэй зохион байгуулалт нь хамгийн сайн хүчин чармайлт юм).
- **Docs** хуудсыг зураг хэлбэрээр экспортлох боломжтой (нэг хуудсанд PNG).

## Хэвлэх

Файл ▸ Засварлагч бүрийн хэвлэх ( ⌘P/ctrl +P) нь хэвлэх цонхыг нээнэ. Docs, PDF , Sheets, Slides болон Markdown нь **Хуудасны бүдүүвч** хэсгийг ердийн хэвлэх цонхондоо, Hangul үүнийг хэвлэхээс урьдчилан харах хэлбэрээр, HTML, Mind Map болон Diagram нь шинэ жижиг хэвлэх цонхонд харуулдаг. Хэрэв та "Хуудасны бүдүүвч" хэсэгт юу ч сонгоогүй бол хэвлэх нь өмнөхтэй адил ажиллана.

- **Байрлал** : Нэг хуудсанд нэг хуудас, хуудас бүрт хэд хэдэн хуудас (2, 4, 6, 9 эсвэл 16), товхимол (зүүн эсвэл баруун талд хавсаргах), зурагт хуудас (хуудас хөндлөн болон доош, давхцах, зүсэх) эсвэл Шошго (шошго бүрт нэг хуудас, ижил хэмжээтэй шошго, ижил хэмжээтэй шошго) -аас аль нэгийг нь сонгоно уу.
- **Зөвхөн сондгой тал, Зөвхөн тэгш тал, Урвуу дарааллаар хэвлэнэ** : хэвлэгчээс гарч байгаа талуудын хэв маягийг хэрэглэсний дараа талуудыг тоолно. Тэдгээрийг хоёр талт хэвлэхгүйгээр хэвлэгч дээр ашигла: нүүрэн талыг нь хэвлэж, цаасыг эргүүлж, дараа нь ар талыг нь хэвлэ.
- **Цаасанд тааруулахын тулд агшаах** : зөвхөн сонгосон цааснаас том хуудсууд жижгэрнэ; жижиг хуудсыг томруулдаггүй. Sheets болон Markdown нь өөрсдийн цаас болон масштабын тохиргоог үргэлжлүүлэн ашигладаг.
- **Саарал өнгө, зургийн нягтрал** : Хуудасны байршлын сонголтоор хэвлэх нь хуудас бүрийг хэвлэгч рүү очихоос өмнө зураг болгон хувиргадаг. Нарийвчлалын хувьд Автомат, 150, 300 эсвэл 600 dpi-г сонгоно уу.
- **Зөвхөн сонголт** : Docs болон Markdown зөвхөн сонгосон текстийг эхний хуудаснаас дахин хэвлэнэ; Слайд нь сонгосон слайдуудыг, PDF сонгосон хуудсыг хэвлэдэг. Sheets нь сонгосон мужийг өмнөх шиг хэвлэдэг.
- **Байршлын диаграмм болон үр дүнг урьдчилан харах** : диаграмм нь хуудасны дугаар бүр цаасан дээр хаана байгааг шууд харуулах ба **Үр дүнг урьдчилан харах** нь яг юу хийгдсэнийг харуулдаг. **Зохицуулсан үр дүнг PDF** нэрээр хадгалан өөр компьютер эсвэл хэвлэх дэлгүүрт ижил схемийг хэвлэнэ үү.
- **Системийн хэвлэх цонх** : товхимолын хувьд богино ирмэг дээр эргүүлсэн хоёр талт хэвлэхийг сонгоно уу. Системийн цонхонд хуудасны хүрээ болон хуудасны тоог байгаагаар нь үлдээнэ үү.

PDF файлууд нь одоогийн хуудасны дараалал, эргэлттэй хэвлэгддэг.

## Гарчиггүй файлууд хаана амьдардаг

Эхний хадгалалтанд таны сонгосон байршил бол түүний гэр юм. Тэр болтол баримт бичигт өөрийн гэсэн файл байхгүй: түүний хадгалагдаагүй контент нь зөвхөн програмын өгөгдлийн хавтсанд сэргээх хуулбар хэлбэрээр хадгалагддаг тул програм гэнэт унтарвал буцаж ирэх боломжтой ([Tabs болон windows](help://tabs-and-windows)-г үзнэ үү). Эхний хадгалалтын дараа л автоматаар хадгална.
