# Кодын агент холбох

GenOffice Загварын контекст протоколоор ярьдаг тул кодлогч нь програмын ашигладаг ижил хөдөлгүүрээр дамжуулан таны баримт бичгийг уншиж, бичиж, үзүүлэх боломжтой. Агент файлын форматыг таамаглаагүй байна: энэ нь гүйцэтгэгчийн баталгаажуулсан ижил тодорхойлолтуудаас бичсэн үйлдлийн схемүүдийг авдаг.

## Үүнийг

програмаас бүртгэж байна. **Тохиргоо ▸ Интеграци** нь үүнийг хийх газар юм. Уг самбар нь хоёр талтай бөгөөд та аль нэгийг нь эсвэл хоёуланг нь ашиглаж болно.

**Ур чадвар.** Энэ машин дээр нэг кодлогчийн нэг мөр олдсон — Клод Код, хуваалцсан хавтас `~/.agents` (Codex, Cursor, Gemini CLI, Copilot CLI болон OpenCode уншдаг), Windsurf - тус бүр нь **Суулгах** , **Шинэчлэх** болон **Устгах** , нэмэх **Өөр хавтас руу суулгах...** , **Ур чадвар (zip) татаж авах** болон **Замыг хуулах** Хэрэв таны туслах жагсаалтад байхгүй бол зааж өгнө үү GenOffice уншдаг хавтас дээр `SKILL.md` -аас эсвэл зипийг хадгалаад туслахдаа суулгахыг зөвшөөрнө үү. Ур чадвар болон MCP зэрэгцэн сууж болно: туслах нь нэгийг нь сонгох бөгөөд тэд яг ижил зүйлийг хийдэг. Эдгээр таван хэрэгслийн аль нэгэнд нь өмнө нь суулгасан хуулбар нь хуваалцсан мөрийн доор жагсаж, шинэчлэгдэж байх болно; Хуваалцсан хавтас ур чадвартай болмогц та тэр хуулбарыг устгаж болно.

**MCP.** Хоёр чиглэлийг санал болгож байна: **Туслах эхлүүлсэн (санал болгосон)** , та үзүүлсэн тохиргоог үйлчлүүлэгчдээ нэмэх ба туслах нь серверийг өөрөө эхлүүлнэ **Орон нутгийн HTTP сервер** , апп нь танд зориулж ажиллуулдаг. Аль ч тохиолдолд туслах нь ярилцаж дуусна GenOffice мөн та хэзээ ч тушаал бичдэггүй.

## Үүнийг

командын мөрөөс бүртгэж байна. Терминал дээрх ижил зүйл бол энэ бол дэвшилтэт зам бөгөөд агент нь цонхны олж чадахгүй газар амьдардаг үед хүрэх зам юм:

```sh
ieumoffice mcp install all
```

Энэ нь энэ машин дээрх кодлогч агентуудыг олж, stdio серверийн оруулгыг тус бүрийн өөрийн тохиргоонд бичиж, үлдсэн файлыг олсон байдлаар нь үлдээдэг. Энэ оруулгыг `ieumoffice` гэж нэрлэсэн. Клод кодын гараар хийсэн бүртгэл нь `claude mcp add --transport stdio ieumoffice -- ieumoffice mcp` юм.

```sh
ieumoffice mcp list             # where each agent stands
ieumoffice mcp install cursor    # just one
ieumoffice mcp uninstall cursor  # take it back out
```

Таны хаа нэгтээ суулгасан агент `--dir <path>` авдаг; `--force` нь аль хэдийн байгаа оруулгыг дахин бичдэг.

`ieumoffice mcp --help` нь серверийн авсан бүх зүйлийг нэг дэлгэц дээр байрлуулдаг: маягтуудыг бүртгэх, устгах, жагсаах, HTTP дээр үйлчлэх, хоёр схемийн туг.

## Үүнийг

туслахгүйгээр ажиллуулж байна. Өөр машин дээрх үйлчлүүлэгчийн хувьд HTTP-ээр үйлчилнэ үү:

```sh
ieumoffice mcp --http 8765 --token <secret>
```

`--host <addr>` хаана сонсохоо өөрчилдөг. Үйлчлүүлэгч рүү ижил жетон дамжуулна уу.

HTTP файлууд дээр бас аялдаг: `PUT /files/<name>` нэгийг нь байршуулдаг, хэрэгсэл бүр замын оронд `http(s)` URL-г авдаг бөгөөд гаралт нь татаж авах URL-ууд болон хангалттай бага бол суулгагдсан эх сурвалжууд болон буцаж ирдэг. Үйлдлүүд, техникийн үзүүлэлтүүд болон Markdown нь аль ч тохиолдолд шугаманд дамждаг.

## Агент юу авах вэ

Тушаал бүр нь хэрэгсэл юм. Сонирхолтой нь:

- **`docs` , `sheet` , `slides`** — програмын өөрийн бичих замаар файл уншиж, засварлана **op** нэг удаа. Шинэ тавцан явж байна `deck_start` , `deck_page` , `deck_build` .
- **`render`** — нэг хуудсанд нэг PNG дүрсийг програмын рендерер гаргасан тул агент тааварлахын оронд слайдыг харах боломжтой.
- **`pdf`** — PDF-ийн текстийн давхарга, хуудас хуудас, програмын процессгүй.
- **`info`** — мета өгөгдөл ба бүтцийн хураангуй нь ихэвчлэн танил бус файлын хамгийн хямд дуудлага юм.
- **`search` , `image` , `media`** — апп-д тохируулсан зүйлээр дамжуулан вэб болон зураг хайх, зураг үүсгэх, медиа дүн шинжилгээ хийх тул агентад өөрийн түлхүүр хэрэггүй. Дараагийн хэсэгт тэд юу ашиглаж болохыг хэлж өгнө.
- **`merge`** — `{{key}}` загварыг бөглөнө үү.

## Хайлт, зураг, медиа: агент

-г юу ашиглаж болох вэ. `ieumoffice` командын эсвэл MCP үйлчлүүлэгчийн хүсэлтийг та апп дотор бичээгүй тул GenOffice болгоомжтой хандана уу.

- **Хайлт** үргэлж ажилладаг бөгөөд анхдагчаар үнэ төлбөргүй байдаг. Хайлтын үйлчилгээ үзүүлэгчийн түлхүүрийг сонгосон тохиолдолд л ашиглана.
- **Зураг үүсгэх нь** нь Тохиргоо доторх зураг үүсгэх сонголтыг дагана. Анхдагч ChatGPT төлөвлөгөө (Кодекс програм) нь Codex програмаар дамжуулан таны ChatGPT төлөвлөгөөг ашигладаг бөгөөд та **-г зөвшөөрөхгүй бол** ашиглахгүй (доороос харна уу). Үгүй бол таны тохируулсан зураг нийлүүлэгчийн түлхүүрийг ашиглана. Маршрутыг санал болгох үед агентын нэрлэсэн загварыг ашигладаг.
- **Зургийг тайлбарлах** тохируулах үед гол үйлчилгээ үзүүлэгчийг ашигладаг. Таны Claude эсвэл Codex захиалга байна **зөвшөөрөхгүй бол ашиглахгүй** .
- **Видео болон аудио** видеог дэмждэг гол үйлчилгээ үзүүлэгч хэрэгтэй.

Захиалга ашиглахыг зөвшөөрөхийн тулд Тохиргоо ▸ AI ▸ **Нарийвчилсан**-г нээгээд **-г асаана уу. Автомат хүсэлтэд** захиалга ашиглахыг зөвшөөрнө үү. Анхааруулга нь хамгийн түрүүнд ирдэг — "Цагийн хязгаарлалт байхгүй тул програм нь хүссэн хэмжээгээрээ хүсэлт илгээх боломжтой бөгөөд тэдгээр нь баримт бичгийн текст болон хуудсынх нь зургийг бүхэлд нь авч явах боломжтой. Аль ч компани таны бүртгэлийг автоматаар ашиглахыг программд зөвшөөрөхгүй бөгөөд таны бүртгэлийг хязгаарлаж болзошгүй." — ба унтраалга нь зөвхөн **-ийн дараа асна. Ямар ч байсан асаана уу** .

Шилжүүлэгч асаалттай байсан ч:

- Хүсэлтийг нэг нэгээр нь авч үздэг. Бусад нь ээлжээ хүлээж байна.
- Цагийн хязгаарлалт байхгүй. Ээлжийг ажлаар бус хүсэлтээр авдаг тул PDF урт орчуулга нь бусад дуудагчдыг хүлээхийн оронд ээлжлэн хийдэг. Хуучин анхааруулгын дор асаалттай унтраалга унтарсан: шинэ анхааруулгыг уншаад дахин асаана уу.
- **-р зөвшөөрөгдсөн төлбөр төлсөн нэвтрэлт Ямар ч байсан ашиглах** энд захиалгад тооцогдохгүй. Үүнийг түлхүүр мэт авч үздэг: хэрэв та үүнийг хиймэл оюун ухаан болгон ашиглахаар сонгосон бол шилжүүлэгч юу ч хэлсэн бай зургийн тайлбарыг түүгээр дамжуулж, тус бүрийг нь нэхэмжлэх болно.

Унтрааж, түлхүүр тохируулаагүй үед уг хэрэгсэл нь функцийг ашиглах боломжгүй гэж хариулж, энэ тохиргоог нэрлэнэ. Агент эхлээд `capabilities` хэрэгслээр шалгаж болно; [командын мөр ба агентуудыг](help://cli)-г үзнэ үү.

## Схемүүд, бага төсөвтэй

`apply` болон `create` нь `ops` , `cells` болон `data` параметрүүдийг `ieumoffice guide <domain> --json`-аас үүсгэсэн нэг үйлдлийн схемээр сурталчилдаг. Энэ нь нарийн бөгөөд жижиг биш юм. Хатуу контекст цонхтой үйлчлүүлэгч оронд нь энгийн массив асууж болно:

```sh
ieumoffice mcp --compact-schemas
GENOFFICE_MCP_COMPACT_SCHEMAS=1 ieumoffice mcp
```

## Яагаад ур чадвар

Үйл ажиллагааны үгсийн санг мэдэхгүй агент таамаглах болно. Энэ ур чадвар нь `ieumoffice guide` хэвлэдэг ижил материал болох лавлагаа болон дизайны удирдамжийг агуулдаг тул туслах нь яг уншсан техникийн мэдээллийг бичдэг. Үүнийг дээд талд байрлах самбараас эсвэл терминалаас `ieumoffice skill` суулгаарай.

## Энэ аппликешнд юу хүрч болох вэ

Сервер нь зөвхөн диск дээрх файлуудаар хязгаарлагдахгүй. GenOffice ажиллаж байх үед агент нь мөн цонхоор ажиллах боломжтой:

- **`open_in_genoffice`** tab доторх файлыг нээж, анхаарлаа төвлөрүүлдэг.
- **`open_documents`** нь таны нээлттэй байгаа баримт бичиг бүрийг жагсааж - ID, төрөл, зам, хадгалагдаагүй өөрчлөлтүүд байгаа эсэх - дараа нь тухайн хүний шууд контентыг уншиж, байранд нь хадгалж эсвэл хааж, хэрэв та хаяхыг хүсээгүй бол эхлээд хадгална.
- **Агуулгын хэрэгслүүд** нь тухайн id (эсвэл замыг) `document` аргумент болгон авдаг тул засвар нь таны аль хэдийн нээгдсэн tab-д бууж, цонхыг харуулахаар шилжинэ.

Хоёр зүйлд хүрэх боломжгүй байна: AI самбар байхгүй, програмын шинэчлэлтийн харилцах цонх хамаарахгүй.

## Локал HTTP серверийн самбар

Доод **Орон нутгийн HTTP сервер** програм нь серверийг туслахад үлдээхийн оронд өөрөө ажиллуулж болно: идэвхжүүлэх шилжүүлэгч, a **Порт** талбай, а **Гүйж байна / Гүйхгүй** үзүүлэлт, **Арын дэвсгэр үүсгэх** (UI-г нээхгүйгээр шууд зам руу бичиг баримт бичих) болон **Үйлчлүүлэгчийн тохиргооны жишээ** үйлчлүүлэгч рүүгээ хуулах. Нээлт **Дэвшилтэт** хоёр холболтын URL-г нэмдэг - Дамжуулж болох HTTP болон хуучин SSE нэг - a **Эрүүл мэндийн үзлэг** URL болон a **Мод бэлтгэх** сервер болон хэрэгслийн үйл ажиллагааг бүртгэдэг локал файл руу шилжүүлж болно **Нээлттэй** , **Сэргээх** эсвэл **Тодорхой** тэндээс. Энэ нь зөвхөн localhost дээр сонсдог.
