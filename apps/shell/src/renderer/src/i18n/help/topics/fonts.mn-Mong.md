# ᠹᠣᠨᠲ

## ᠦᠰᠦᠭ ᠦᠨ ᠬᠦᠰᠦᠨᠦᠭᠲᠦ ᠶᠢ

ᠦᠰᠦᠭ ᠲᠡᠮᠲᠡᠭᠯᠡᠬᠦ ᠨᠢ ᠪᠦᠷ ᠨᠠᠶᠢᠷᠠᠭᠤᠯᠤᠭᠴᠢ ᠶᠢᠨ ᠭᠡᠷ ᠦᠨ tab ᠳᠡᠭᠡᠷ᠎ᠡ ᠃

ᠡᠯ᠎ᠡ ᠨᠠᠶᠢᠷᠠᠭᠤᠯᠤᠭᠴᠢ ᠶᠢᠨ ᠦᠰᠦᠭ ᠢ ᠰᠣᠩᠭᠣᠬᠤ ᠺᠣᠨᠢ ᠨᠡᠶᠢᠯᠡᠯ᠄ ᠲᠤᠰ ᠭᠠᠵᠠᠷ ᠲᠤ ᠤᠭᠰᠠᠷᠠᠭᠰᠠᠨ ᠦᠰᠦᠭ᠌ + ᠲᠠᠪᠴᠠᠩ ᠳᠤ ᠨᠡᠢᠢᠳᠡ ᠶᠢᠨ ᠴᠢᠨᠠᠷ ᠲᠠᠢ ᠬᠦᠮᠦᠰ (ᠶᠡᠷᠦ ᠶᠢᠨ Windows ᠪᠠ macOS ᠭᠡᠷ ᠪᠦᠯᠢ᠂ ᠦᠷᠦᠨᠡᠳᠡᠬᠢ ᠶᠢᠨ ᠪᠠ CJK᠂ ᠡᠭᠦᠨ ᠢ ᠪᠠᠭᠲᠠᠭᠠᠭᠰᠠᠨ ᠲᠤᠰ ᠭᠠᠵᠠᠷ ᠤᠨ ᠨᠡᠷ᠎ᠡ ᠶᠢᠨ ᠨᠡᠷ᠎ᠡ ᠶᠢ ᠪᠦᠷ ᠲᠡᠭᠦᠨ ᠦ ᠭᠡᠷ ᠦᠨ ᠰᠢᠰᠲ᠋ᠧᠮ ᠦᠨ ᠮᠡᠳᠡᠭᠦᠯᠦᠯᠲᠡ ᠶᠢ ᠪᠠᠭᠲᠠᠭᠠᠨ᠎ᠠ) ᠃ ᠰᠢᠰᠲ᠋ᠧᠮ ᠨᠢ ᠲᠤᠰ ᠭᠠᠵᠠᠷ ᠤᠨ ᠦᠰᠦᠭ ᠢ ᠪᠦᠷᠢᠳᠬᠡᠬᠦ ᠦᠶ᠎ᠡ ᠳᠦ ᠂ ᠦᠨᠡᠨ ᠣᠷᠣᠰᠢᠵᠤ ᠪᠠᠶᠢᠭ᠎ᠠ ᠶᠠᠭᠤᠮ᠎ᠠ ᠪᠠᠷ ᠨᠠᠷᠢᠨ ᠬᠦᠰᠦᠨᠦᠭᠲᠦ ᠶᠢᠨ ᠬᠦᠰᠦᠨᠦᠭᠲᠦ ᠶᠢ ᠲᠣᠭᠲᠠᠭᠠᠬᠤ

ᠬᠦᠰᠦᠨᠦᠭᠲᠦ ᠳᠡᠬᠢ ᠠᠯᠢᠪᠠ ᠦᠰᠦᠭ ᠦᠨ ᠦᠰᠦᠭ ᠢ ᠪᠦᠷ ᠡᠨᠡ ᠺᠤᠮᠫᠢᠺ ᠳᠡᠭᠡᠷ᠎ᠡ ᠤᠭᠰᠠᠷᠠᠭᠰᠠᠨ ᠡᠰᠡᠭᠦᠯ᠎ᠡ ᠲᠤᠰ ᠫᠧᠩ ᠳᠦ ᠢᠷᠡᠵᠡᠢ ᠃ ᠶᠠᠭᠤᠨ ᠴᠤ ᠪᠠᠭᠤᠯᠭᠠᠭᠰᠠᠨ ᠦᠭᠡᠢ ᠃

## ᠨᠢᠭᠡ ᠦᠰᠦᠭ ᠦᠨ ᠦᠰᠦᠭ ᠦᠨ ᠮᠠᠲ᠋ᠧᠷᠢᠶᠠᠯ ᠢ ᠤᠭᠰᠠᠷᠠᠬᠤ ( Slide)
