# PDF хэрэгслүүд

Өдөр тутмын PDF даалгаврын цонх, даалгавраас эхлэн. Үр дүн үргэлж шинэ файл хэлбэрээр хадгалагдаж, эх хувилбар өөрчлөгдөхгүй. Энэ цонхны хэрэгслүүд зөвхөн энэ компьютер дээр ажилладаг бөгөөд хиймэл оюун ухаан ашигладаггүй.

## Хэрхэн ажилладаг

1. Нүүр дээр **PDF хэрэгслүүд** карт дээр дарна уу. Тусдаа цонх нээгдэнэ.
2. Даалгавар сонгож, шаардлагатай файлуудыг сонгож, тохиргоог нь тохируулж, **Save as new file** дарна уу.
3. Хадгалсны дараа **Open in a tab** үр дүнг нэг дор харуулж, **Show in folder** байгаа хавтсыг нээнэ.

Картууд **PDF засварлагч** сонгосон PDF редакторт нээх tab . Туузны командыг сонгоно уу.

## Мэдэж авахад

- Эх файл дээр хадгалах эсвэл хадгалагдаагүй өөрчлөлттэй нээлттэй файл дээр хадгалах боломжгүй.
- Нууц үгээр хамгаалагдсан PDF нь бусад хэрэгслүүдэд зөвхөн **Нууц үгийг устгах** дараа ажиллана. Нууц үг нь мэдэхгүй файлыг нээх боломжгүй.
- **Засварлах файл** зөвхөн уншиж болох хэсгүүдийг буцаана. Шинэ файлыг нээгээд ямар ч хуудас алга болоогүй эсэхийг шалгаарай.
- **Зөвхөн кандидатуудыг харуулсан хоосон хуудсыг устгах** Зөвхөн сонгосон хуудсууд устгагдана, нэг тэмдэгттэй хуудас хэзээ ч нэр дэвшигч биш.
- **Тайлбаруудыг устгах** эд ангиудын талбаруудыг хадгалах бөгөөд зөвхөн та тэднийг сонговол холбоосуудыг устгана. Устгагдсан тайлбаруудын агуулга шинэ файлд үлдэхгүй.
- **Текст хэлбэрээр хадгалах** зөвхөн текст давхаргыг уншдаг. Текст нь зураг хэлбэртэй хуудсууд, жишээлбэл, сканертай хуудсууд хоосон гарна.
