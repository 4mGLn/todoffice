# HTML засварлагч

HTML засварлагч нь .html / .htm-г **preview** (үзүүлсэн хуудас) болон **source** гэсэн хоёр горимоор нээдэг

- **Урьдчилсан харах** : жинхэнэ дүрслэл; харьцангуй хэв маягийн хуудас болон зураг файлын хажууд ачаалагдана.
- **Preview inspector** : элемент сонгохын тулд дарж, текстийг нь засахын тулд давхар товшино, хэрэгслийн самбарыг устгаж, сонголтын эсрэг AI-аас асуух.
- **Slides** : слайдын хуудсанд урьдчилсан харагдацын зүүн талд хуудас өөрөө зурсан слайдын жагсаалт гарна; нэгийг дарж тэр слайдыг харуулна. Урьдчилсан харагдацыг дахин ачаалсан засвар нь таны байсан слайд руу буцаж очдог бөгөөд слайдын текстэд бичсэн товчлуурууд слайдыг хэзээ ч эргүүлдэггүй.
- **Эх үүсвэрийн горим** : HTML-ийг засах; ctrl+F олвол, Бүгдийг нь солих нь дахин бичигдсэн тэмдэглэгээг хадгална.
- **Хадгалах** : байт-үнэнч (BOM/CRLF/төгсгөлийн шинэ мөр хадгалагдсан); өөрчлөгдөөгүй хадгалалтууд дахин бичдэггүй.
- **Zoom** : ctrl+wheel / pinch нь урьдчилсан харагдацыг өргөтгөдөг; ctrl+Z урьдчилсан харагдац дотор сүүлийн засварыг буцаана.
- **AI-аас нуух** : эх горимд сонголт дээр баруун товшиж — элементийн агуулга, шинж чанарын утга, скриптийн мөрүүд — дээр дарж, загвар оронд нь орлуулагч гарч ирнэ; дүрслэгдсэн хуудас хэзээ ч өөрчлөгдөхгүй (дэлгэрэнгүйг AI самбарын бүлэгт).

## Хэрэгслийн самбар

Урьдчилан харах дээр ямар ч элемент дээр дарвал түүний дээр

![The floating toolbar over a selected element](img/html-toolbar.png)

- хэрэгслийн самбар хөвж гарч ирнэ. **Файл ба түүхийн** : Хадгалах, Хадгалах, Буцаах, Дахин хийх, Хайх; **AutoSave** унтраалга нь өөрчлөлтийг цаг хэмжигч дээр бичдэг.
- **Урьдчилан харах / Эх сурвалж** унтраалга; **Present** нь хуудсыг бүтэн дэлгэцээр харуулна.
- **Форматлах** : зузаан, курсив, фонтын хэмжээг өсгөх/бууруулах; **стиль самбар** сонгосон элементэд (өнгө болон бусад).
- **Оруулах** : гарчиг, параграф, хүснэгт, зураг (линкээр), бусад.
- **Зурагтай холбоотой үйлдлүүд** (зураг сонгогдсон үед): тайрах, **арын хэсгийг устгах**, солих, харьцааг түгжих.
- **Элементтэй холбоотой үйлдлүүд** (урьдчилсан үзлэгийн инспектор-д элемент сонгогдсон үед): устгах, хувилах, дээш/доош зөөх.
- **AI товч** : AI самбарыг нээх; сонгосон элементийн талаар шууд асуух.

## Экспортлох

Файл цэс, бүгд орон нутгийн бөгөөд үр дүнг хаана байрлуулахыг асууна:

- **Word хэлбэрээр экспортлох...** ба **Экспорт PDF ...** бодит .docx эсвэл .pdf бичих боломжтой.
- **Экспорт ODT ...** нь Word экспорттой ижил хөрвүүлэлтээр .odt (OpenDocument текст) бичдэг; замдаа ямар нэг зүйл өөрчлөгдсөн эсвэл унасан тохиолдолд жагсаалтыг харж эхлээд баталгаажуулна.
- **Нэг файлын HTML хэлбэрээр экспортлох...** нь зургуудыг агуулсан .html бичнэ. Одоогоор нээлттэй байгаа файлыг давхар бичихгүй, мөн хэдэн зураг оруулж чадаагүйг заана.

## Скелетон оруулах

Хоосон хуудсанд **Insert ▸ Insert skeleton** нь хамгийн бага стандарт горимын баримт бичгийг бичнэ:

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title></title>
  </head>
  <body></body>
</html>
```

Тус бүрийн хэсэг нь учиртай тул бичих зүйл биш, тушаал юм:

- **баримт бичгийн төрөл** эсвэл урьдчилсан тойм нь өөр дүрмийн дагуу хайрцгийн хэмжээ болон хүснэгтийн зохион байгуулалтыг дагах эргэлзмээр горимд ажилладаг;
- **`lang`** эсвэл дэлгэцийн уншигч дээр хуудсыг унших хэл байхгүй бөгөөд хөтчөөс буруу фонтыг болон үгийн алдааны шалгагчийг сонгодог;
- **тэмдэгтийн багц** эсвэл латин бус текстийн хуудсыг mojibake болгон задлах боломжтой;

Харагдах талбарын meta зориудаар байхгүй: энэ нь хөдөлгөөнт харагдах талбар нөлөөлөхгүйгээр ширээний самбарт харагдана.

`lang` нь апп-ын UI хэл дагалддаг, тиймээс та оруулж байгаа скелетон нь таны багаж хэрэгсэл аль хэдийн тохируулсан зүйлтэй нийцэж байна. Дараа нь чөлөөтэй засварлаж болно.

Энэхүү зүйл зөвхөн засварлах горимд гарч ирдэг бөгөөд баримт бичиг хоосон байх үед л идэвхтэй — агуулга байгаа үед ямар ч скелетнийг _оруулах_ зүйл байхгүй.

## Тэгшитгэлийг засах

Бичвэрийг харагдахуйцаар бичих эсвэл LaTeX-ийг засах. Хадгалсан HTML нь дараагийн засварт эх үүсвэрийг хадгалдаг.

Хөрөөлийн самбараас Тэгшитгэл оруулахыг сонгоно уу. Харагдах талбар, загвар эсвэл LaTeX ашиглаж, дараа нь хэрэглэнэ. Урьдчилсан үзэлт дээр хадгалсан тэгшитгэлийг дарж дахин засварлаарай. Мөрийн доторх математик хувилбарын хувьд догол мөрийн хувилбарыг унтрааж, догол мөрийг сонгоно; тэгшитгэл тухайн догол мөрт нэмж орох болно.

Төсөлдэвшгүй илэрхийллийг алдахгүй: тэгшитгэл нь LaTeX эх үүсвэрийг хадгалж, хуудсан дээр энгийн текстийг харуулж, ингэснээр та дахин нээж засварлах боломжтой.
