## ᠦᠨᠳᠦᠰᠦᠨ

## ᠳᠡᠰ ᠳᠠᠷᠠᠭ᠎ᠠ ᠪᠠᠨ ᠰᠠᠬᠢᠵᠤ

ᠨᠢᠭᠡ ᠵᠦᠢᠯ ᠦᠨ tab ᠶᠢ ᠲᠠᠲᠠᠵᠤ ᠡᠮᠬᠢ ᠲᠢᠭᠯᠢᠮ ᠢ ᠳᠠᠬᠢᠨ ᠭᠠᠷᠬᠤ; ᠵᠡᠷᠭᠡᠯᠳᠡᠭᠡ ᠠᠶᠢᠯ ᠭᠡᠷ ᠦᠨ ᠬᠢᠨᠢ ᠬᠠᠵᠠᠭᠤ ᠲᠡᠰᠢ ᠶᠠᠪᠤᠵᠤ ᠂ ᠲᠡᠰ ᠳᠠᠷᠠᠭᠠᠯᠠᠯ ᠢ ᠲᠠᠯᠪᠢᠨ᠎ᠠ ᠃ ᠳᠥᠷᠪᠡᠨ ᠺᠸᠯᠰᠧᠯ ᠦᠨ ᠦᠬᠦᠬᠦ ᠣᠷᠣᠨ ᠨᠢ ᠳᠥᠭᠥᠮ ᠤᠳᠬ᠎ᠠ ᠪᠠᠷ ᠬᠠᠪ ᠰᠠᠵᠢᠵᠤ ᠪᠣᠯᠬᠤ ᠦᠭᠡᠢ

## ᠤᠳᠭ᠎ᠡ ᠶᠢᠨ ᠹᠢᠯᠣ᠋

ᠪᠠᠷᠠᠭᠤᠨ ᠢᠶᠠᠷ ᠨᠢᠭᠡ tab **Open in New Window**   — ᠤᠷᠠᠭᠤᠯᠵᠤ ᠪᠣᠯᠬᠤ ᠪᠢᠴᠢᠭ᠌ ᠮᠠᠲ᠋ᠧᠷᠢᠶᠠᠯ ᠪᠣᠯᠭᠠᠨ ᠳᠤ tab **Close** ᠂  ᠨᠢ ᠬᠠᠭᠠᠵᠤ ᠪᠣᠯᠬᠤ ᠦᠭᠡᠢ tab ᠳᠡᠭᠡᠷ᠎ᠡ ᠬᠠᠷᠠᠭᠳᠠᠬᠤ ᠦᠭᠡᠢ ᠃ ᠬᠣᠶᠠᠭᠤᠯᠠ ᠨᠢ ᠪᠦᠷ app ᠬᠡᠯᠡᠨ ᠦ ᠦᠭᠡ ᠶᠢ ᠳᠠᠭᠠᠵᠤ ᠪᠠᠶᠢᠨ᠎ᠠ

## ᠴᠣᠩᠬᠣᠨ ᠤ ᠥᠭᠡᠳᠡ ᠲᠠᠲᠠᠬᠤ

**Drag a tab out of the strip** ( ᠰᠢᠨ᠎ᠡ ᠴᠣᠩᠬᠣᠨ ᠳᠤ ᠨᠡᠭᠡᠭᠡᠬᠦ ᠶᠢ ᠬᠡᠷᠡᠭ᠍ᠯᠡᠨ᠎ᠡ ) ᠂ ᠲᠡᠷᠡ ᠨᠢ ᠠᠮᠢᠳᠤ ᠮᠠᠲ᠋ᠧᠷᠢᠶᠠᠯ ᠢ ᠠᠴᠢᠶᠠᠯᠠᠭᠰᠠᠨ ᠥᠪᠡᠷ ᠦᠨ ᠴᠣᠩᠬᠣ ᠪᠣᠯᠵᠠᠢ ᠃ ᠲᠡᠭᠦᠨ ᠢ ᠪᠤᠴᠠᠭᠠᠨ ᠠᠪᠴᠤ ᠲᠡᠭᠦᠨ ᠢ ᠬᠠᠯᠢᠬᠤ ᠬᠠᠭᠤᠳᠠᠰᠤᠨ ᠳᠤ ᠳᠠᠬᠢᠨ ᠵᠠᠯᠭᠠᠨ᠎ᠠ ᠃ ᠰᠠᠯᠤᠭᠠᠢ ᠲᠠᠢ ᠴᠣᠩᠬᠣ ᠪᠣᠯ ᠪᠦᠷᠢᠨ ᠬᠠᠵᠠᠭᠤ ᠶᠢᠨ ᠪᠠᠷᠠᠭ᠎ᠠ — ᠲᠡᠨᠳᠡ ᠵᠠᠰᠠᠭᠠᠳ ᠬᠠᠳᠠᠭᠠᠯᠠᠬᠤ ᠶᠠᠪᠤᠳᠠᠯ

## ᠪᠦᠬᠦ ᠬᠣᠪᠢ ᠫᠷᠣᠭ᠌ᠷᠠᠮ ᠤᠨ ᠨᠡᠷᠡᠰ

ᠬᠪᠰᠤᠨ ᠤ ᠭᠠᠷᠴᠠᠭ ᠠᠴᠠ ᠬᠡᠲᠦᠷᠡᠬᠦ ᠦᠶ᠎ᠡ ᠳᠦ ᠂ ᠵᠢᠷᠤᠭ ᠤᠨ ᠪᠠᠷᠠᠭᠤᠨ tab ᠶᠢᠨ ᠦᠵᠦᠭᠦᠷ ᠲᠡᠬᠢ ᠵᠢᠵᠢᠭ ᠪᠠᠮᠰ ᠤᠨ ᠲᠡᠮᠲᠡᠭ ᠪᠦᠬᠦ ᠪᠥᠷᠢᠨ ᠭᠠᠷᠴᠠᠭ ᠢ ᠨᠡᠭᠡᠭᠡᠨ᠎ᠡ （ ᠤᠤᠯ ᠤᠨ ᠵᠠᠭᠤᠰᠢ ᠶᠢᠨ ᠲᠣᠪᠶᠣᠭ ᠢ ᠂ ᠠᠭᠤᠯᠭ᠎ᠠ ᠶᠢᠨ ᠣᠷᠣᠨ ᠳᠤ ᠶᠡᠷᠦ ᠡᠴᠡ ᠬᠠᠮᠠᠭᠠᠯᠠᠬᠤ ᠦᠭᠡᠢ ) ᠃ ᠰᠣᠨ ᠲᠣᠪᠴᠢ ᠪᠠᠷ ᠰᠤᠭᠤᠨ ᠤ ᠲᠣᠪᠴᠢ ᠪᠠᠷ ᠰᠤᠩᠭ᠋ᠤ

## ᠵᠠᠰᠠᠭᠤᠯᠬᠤ ᠫᠷᠤᠭ᠌ᠷᠠᠮ ᠪᠦᠷᠢ ᠶᠢᠨ ᠳᠣᠲᠣᠷ᠎ᠠ ᠪᠠᠨ ᠪᠠᠭᠠᠵᠢ ᠶᠢᠨ ᠪᠠᠭᠠᠵᠢ ᠶᠢᠨ ᠮᠥᠷ

ᠨᠠᠢ᠌ᠷᠠᠭᠤᠯᠤᠭᠴᠢ ᠪᠥᠷᠢ tab ᠶᠢᠨ ᠳᠡᠭᠡᠷ᠎ᠡ ᠨᠢ ᠨᠢᠭᠡ ᠪᠠᠭᠠᠵᠢ ᠶᠢᠨ ᠪᠠᠭᠠᠲᠤᠷ ᠤᠨ ᠮᠥᠷ ᠲᠡᠢ （ ᠨᠠᠶᠢᠷᠠᠭᠤᠯᠤᠭᠴᠢ ᠨᠢᠭᠡᠪᠦᠷᠢ ᠶᠢᠨ ᠳᠦᠷᠢ ᠪᠠᠢ᠌ᠷᠢᠯᠠᠯᠲᠠ ᠨᠢ ᠠᠳᠠᠯᠢ ᠦᠭᠡᠢ ）

- **Save** (⌘S/ctrl+S) ᠪᠣᠯᠤᠨ **Save As**
- **Undo / Redo** ᠄ ᠤᠯᠠᠨ ᠲᠠᠪᠬᠤᠷᠭ᠎ᠠ ᠪᠠᠶᠢᠬᠤ ᠳᠤ ᠂ ᠨᠠᠶᠢᠷᠠᠭᠤᠯᠤᠭᠴᠢ ᠪᠦᠷᠢ ᠥᠪᠡᠷ ᠤᠨ ᠲᠡᠦᠭᠡ ᠪᠡᠨ ᠬᠠᠳᠠᠭᠠᠯᠠᠵᠤ ᠪᠠᠶᠢᠨ᠎ᠠ
- **Find** （ ctrl+F ): ᠲᠡᠷᠡ ᠨᠠᠶᠢᠷᠠᠭᠤᠯᠤᠭᠴᠢ ᠶᠢᠨ ᠡᠷᠢᠬᠦ ᠬᠠᠪᠲᠠᠰᠤᠨ ᠢ ᠨᠡᠭᠡᠭᠡᠨ᠎ᠡ
- **AutoSave** ᠢ ᠨᠡᠭᠡᠭᠡᠬᠦ ᠳᠦ ᠥᠭᠡᠷᠡᠴᠢᠯᠡᠯᠲᠡ ᠶᠢ ᠴᠠᠭ ᠢᠶᠠᠷ ᠳ᠋ᠢᠰᠺ ᠳᠡᠭᠡᠷ᠎ᠡ ᠪᠢᠴᠢᠨ᠎ᠡ ᠃ ᠠᠵᠢᠯᠯᠠᠬᠤ ᠪᠠᠨ ᠵᠣᠭᠰᠣᠭᠰᠠᠨ ᠦᠶ᠎ᠡ ᠳᠦ ᠵᠥᠪᠬᠡᠨ ᠭᠠᠷ ᠢᠶᠠᠷ ᠬᠠᠳᠠᠭᠠᠯᠠᠵᠤ ᠠᠪᠤᠨ᠎ᠠ ( tab / ᠭᠠᠷᠴᠠᠭ ᠤᠨ ᠳᠡᠭᠡᠷᠡᠬᠢ ᠬᠠᠳᠠᠭᠠᠯᠠᠭᠰᠠᠨ ᠲᠡᠮᠲᠡᠭ ᠨᠢ ᠲᠠᠨ ᠳᠤ ᠰᠠᠨᠠᠭᠤᠯᠤᠭᠳᠠᠨ᠎ᠠ )
