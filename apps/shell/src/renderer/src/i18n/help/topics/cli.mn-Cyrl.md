# Командын мөр ба агентууд

Суулгах бүр нь `ieumoffice` командыг илгээдэг бөгөөд энэ нь цонхтой ижил хөдөлгүүрүүдийг ажиллуулдаг - ижил задлагч, ижил бичигч, ижил дүрслэгч. Аппликешн хадгалдаг файл болон тушаалын бичсэн файл нь ижил файл бөгөөд програмын AI самбарыг дамжуулсан шалгах нь тушаалыг дамжуулсан шалгах явдал юм.

```sh
ieumoffice --help          # every command
ieumoffice guide slides    # the op reference, for writing your own
```

`ieumoffice --help` нь нэг дэлгэцэн дээрх бүх гадаргуу юм: команд бүр нь юу хийдгийг харуулсан мөртэй, дараа нь глобал сонголтууд болон гарах кодууд.

## Тушаал авч байна

Тушаал нь програм дотор ирдэг. Үүнийг нэрээр нь ашиглахын тулд `ieumoffice install-cli`-г нэг удаа ажиллуулна уу: Windows дээр энэ нь таны хэрэглэгч `PATH` командыг агуулсан хавтсыг нэмж, дараа нь нээх терминалууд үүнийг олно. **Тохиргоо ▸ Интеграцчлал** нь таны терминал тушаалыг аль хэдийн олсон эсэхийг, хэрэв олохгүй бол яг ажиллах мөрийг харуулдаг.

Кодлох агентуудад ийм алхам хэрэггүй. Апп нь командыг `~/.ieumoffice/launcher`-д хаана байгааг бичдэг бөгөөд тэд үүнийг тэндээс олдог.

## Мэдэх үнэ цэнэтэй тушаалууд

| Тушаал            | Юу хийдэг вэ                                                                                                                                                                                                        |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `open`            | Програм дээр баримт бичгийг нээх; Хэрэв програм ажиллахгүй байвал програмыг эхлүүлнэ.                                                                                                                               |
| `selection`       | Апп ажиллаж байх үед тухайн файлд хэрэглэгчийн сонгосон зүйл нь "энэ" / "энд" гэсэн заагч юм. Файлын аль засварлагчаас үл хамааран блокийн муж, хуудасны муж, слайд элемент эсвэл хуудсыг буцаана.                  |
| `convert`         | Програмын өөрийн хөдөлгүүрийг ашиглан формат хооронд хөрвүүлэх.                                                                                                                                                     |
| `create`          | Бүтэцлэгдсэн контентоос баримт үүсгэх.                                                                                                                                                                              |
| `render`          | Хуудас тус бүр нэг PNG дүрсийг буулгагчаар байрлуулна.                                                                                                                                                              |
| `pdf`             | Ямар ч програмын процессгүйгээр PDF-н текстийн давхаргыг хуудас бүрээр нь уншаарай.                                                                                                                                 |
| `read-url`        | Вэб хуудасны текстийг командын мөрөөс уншина уу — нийтлэл, баримт бичиг эсвэл ур чадварын холбоос; текстийг хэвлээд `--offset` -аар үргэлжлүүлнэ.                                                                   |
| `info`            | Мета өгөгдөл болон баримт бичгийн бүтцийн хураангуй.                                                                                                                                                                |
| `search`          | Вэб эсвэл зургийн хайлт: өгөгдмөлөөр үнэ төлбөргүй хайлт эсвэл таны түлхүүрийг апп-д сонгосон хайлтын үйлчилгээ үзүүлэгч.                                                                                           |
| `image` / `media` | Зураг үүсгэх, эсвэл зураг, видео эсвэл аудио файлын талаар тайлбарлаж, асуулт асуугаарай.                                                                                                                           |
| `merge`           | `{{key}}` орлуулагчийг `.docx` , `.pptx` эсвэл `.xlsx` загварт бөглөнө үү.                                                                                                                                          |
| `capabilities`    | Энэ машин дээр хиймэл оюун ухааны ямар функцууд (хайлт, зураг үүсгэх, зураг болон видео шинжилгээ) боломжтой, ямар замаар явж байгааг мэдээлнэ үү.                                                                  |
| `guide`           | Гүйцэтгэгчийн баталгаажуулдаг ижил тодорхойлолтоос үүссэн ажлын лавлагаа болон дизайны гарын авлага нь `apply`-ийн хүлээн зөвшөөрсөн зүйлээс хазайж чадахгүй. `--json` нь үүнийг үйлдлийн схем бүрийн хамт буцаана. |
| `install-cli`     | `ieumoffice`-г `PATH` дээр тавь.                                                                                                                                                                                    |
| `skill`           | Энэ машинаас олдсон кодлогч агентуудыг жагсааж, тэдгээрт GenOffice ур чадварыг суулгаж эсвэл шинэчил.                                                                                                               |
| `mcp`             | Команд бүрийг Загвар контекст протоколын хэрэглүүр болгон үйлчил. **Кодлох агентыг холбох**-г үзнэ үү.                                                                                                              |

## Засварлах: баримт бичиг, хуудас, слайд

Тус бүр `ieumoffice docs` , `ieumoffice sheet` болон `ieumoffice slides` эхлээд дэд команд авдаг - `read` , `apply` , `check` , мөн слайдын хувьд `audit` , `render` , `replace` - мөн програмын ашигладаг ижил бичих замаар дамждаг. Тэд нэг үгийн санг хуваалцдаг: a **op** нь нэг засвар бөгөөд a **техникийн үзүүлэлт** дарааллаар хэрэгжсэн үйлдлийн жагсаалт юм.

```sh
ieumoffice sheet read report.xlsx
ieumoffice slides apply deck.pptx --ops ops.json --dry-run
ieumoffice docs apply brief.docx --ops ops.json
```

`--dry-run` багц юу хийхийг мэдээлдэг бөгөөд юу ч бичихгүй. Энэ нь техникийн үзүүлэлтийг буухаас өмнө шалгах хямд арга юм. Аппликешн дээрх AI самбар нь яг эдгээр үйлдлийн системүүд дээр ажилладаг тул та түүнээс хүссэн бүх зүйлээ скрипт бичиж болно.

## Хайлт, зураг, медиа командууд

`search` , `image` болон `media` нь Тохиргоо ▸ AI ▸ Нарийвчилсан хэсэгт байгаа апп-д тохируулагдсан зүйлийг ашиглана.

- `search` үргэлж ажилладаг. Энэ нь анхдагчаар үнэгүй хайлт эсвэл таны түлхүүрийг сонгосон хайлтын үйлчилгээ үзүүлэгчийг ашигладаг.
- `image` Тохиргоо дотроос зураг үүсгэх сонголтыг дагана. ChatGPT төлөвлөгөөний (Кодекс програм) өгөгдмөлөөр энэ нь Codex програмаар дамжуулан таны ChatGPT төлөвлөгөөтэй нийцдэг, гэхдээ та автомат дуудлага хийх захиалгыг зөвшөөрсөн үед л ( **анхдагчаар унтраа** үзнэ үү [Кодлох агентыг холбож байна](help://mcp) ). Үгүй бол таны тохируулсан зураг нийлүүлэгчийн түлхүүрийг ашиглана. `--model` тухайн маршрут загварыг санал болгох үед ашиглагддаг; эс бөгөөс тушаал нь таны ашиглаж болох загваруудад хариулах болно. Хамт өгсөн зургууд `--ref` хоёр чиглэлд ажиллах.
- Зураг дээрх `media` нь тохируулагдсан үед гол үйлчилгээ үзүүлэгчийг ашигладаг. Энэ нь таны Клауд эсвэл Кодексийн захиалгыг зөвхөн таныг зөвшөөрсөн үед ашиглах бөгөөд **нь анхдагчаар** унтраалттай байдаг; [Кодлох агентыг холбох нь](help://mcp) шилжүүлэгч болон түүний хязгаарыг тайлбарладаг.
- Видео эсвэл аудио дээрх `media`-д видеог дэмждэг гол үйлчилгээ үзүүлэгч хэрэгтэй.

`ieumoffice capabilities --json` энэ бүхнийг хиймэл оюун ухаан руу залгахгүйгээр мэдээлдэг. Түүний `detail` нь:

| Талбай                                                                           | Юу гэж хэлдэг                                                                                                                                                                                                                      |
| -------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `search`, `image_search`, `image_generation`, `image_analysis`, `video_analysis` | Онцлог бүрийн хувьд: `available` ; `via` , хэн хариулдаг; `route` , `free` , `key` эсвэл `subscription` - ийн нэг ; `metered: true` төлбөр төлснөөр нэвтрэх; болон, онцлог боломжгүй үед, `message` , тушаал нь өөрөө хариу текст. |
| `media_analysis`                                                                 | Хуучин скриптүүдэд хадгалагдсан: `image_analysis` , эсвэл зөвхөн видео ажиллах үед `video_analysis`-тай адил.                                                                                                                      |
| `automatic_calls`                                                                | `subscription_enabled` ба `used` асаалттай байх үед автомат хүсэлтийг сүүлийн нэг цагийн дотор (зөвхөн мэдээллийн зорилгоор) хянана, `limit` болон `remaining` үргэлж `null` .                                                     |
| `app`                                                                            | `available` : програмыг команд эхлүүлэх боломжтой газарт суулгасан эсэх.                                                                                                                                                           |
| `settings_path`                                                                  | Эдгээр хариултыг уншсан тохиргооны файл.                                                                                                                                                                                           |

`image` эсвэл `media` ажиллах боломжгүй үед тушаал 4 болон `error: "app_unavailable"` кодоор гарах ба `detail.errorCode` яагаад гэдгийг хэлнэ. `unavailable` нь энэ функцэд юу ч тохируулаагүй гэсэн үг тул дахин оролдоход тус болохгүй. `rate-limit` `detail.resetsAt` буюу дахин хүсэлт гаргах боломжтой цаг (миллисекундээр) ирдэг.

## Энэ

компьютер дээр юу хадгалагддаг. Хоёр файл хоёулаа таны хэрэглэгчийн хавтас доторх `.ieumoffice` хавтсанд байна:

- `~/.ieumoffice/launcher` нь програмын тушаал хаана байгааг бүртгэдэг тул кодлогч нь таны `PATH` дээр байхгүй байсан ч үүнийг олдог.
- `~/.ieumoffice/cli-audit.jsonl` нь гүйцэтгэсэн тушаал болгонд нэг мөр авдаг - тушаал, түүний аргументууд болон үр дүн - ингэснээр та агент юу хийснийг дараа нь харах боломжтой.

## Загвар контекст протокол

`ieumoffice mcp` нь команд бүрийг MCP хэрэгслээр үйлчилдэг бөгөөд `ieumoffice mcp install <agent|all>` үүнийг кодлогчийн өөрийн тохиргоонд бүртгэдэг. Энэ талын **Кодлох агентыг** холбохыг үзнэ үү.

## Тушаал юу хийдэггүй вэ

Энэ нь файлыг уншиж, бичдэг. Энэ нь програм биш: цонх байхгүй, програмын шинэчлэлтийн цонх ажиллахгүй. Цонх хэрэгтэй бүх зүйл - AI самбар, QC дамжуулсан слайдыг дамжуулдаг - таныг файлыг нээхийг хүлээх хэрэгтэй. `ieumoffice render` нь танд үүнгүйгээр пикселүүдийг авах бөгөөд `ieumoffice slides` нь тавцангийн зохион байгуулалтыг бие даан шалгадаг.
