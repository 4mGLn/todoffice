# ᠵᠠᠷᠯᠢᠭ ᠤᠨ ᠮᠥᠷ ᠪᠠ ᠠᠭᠧᠨᠲ

ᠶᠠᠮᠠᠷᠪᠠ ᠲᠣᠨᠣᠭᠯᠠᠯ ᠪᠣᠯᠭᠠᠨ ᠳᠤ ᠨᠢᠭᠡ `ieumoffice` ᠵᠠᠷᠯᠢᠭ ᠲᠠᠢ ᠂ ᠲᠡᠭᠦᠨ ᠦ ᠴᠣᠩᠬᠣ ᠲᠠᠢ ᠠᠳᠠᠯᠢ ᠬᠦᠳᠡᠯᠭᠡᠭᠦᠷ ᠢ ᠠᠵᠢᠯᠯᠠᠭᠤᠯᠤᠨ᠎ᠠ — ᠠᠳᠠᠯᠢ ᠨᠢᠭᠡ ᠵᠦᠢᠯ ᠦᠨ ᠢᠯᠭᠠᠪᠤᠷᠢᠯᠠᠭᠴᠢ ᠂ ᠨᠢᠭᠡ ᠪᠢᠴᠢᠯᠭᠡ ᠲᠡᠢ ᠂ ᠠᠳᠠᠯᠢᠬᠠᠨ ᠢᠯᠡᠷᠡᠭᠦᠯᠦᠭᠴᠢ ᠶᠢ ᠠᠵᠢᠯᠯᠠᠳᠠᠭ ᠃ app ᠨᠢ ᠬᠠᠳᠠᠭᠠᠯᠠᠭᠰᠠᠨ ᠨᠢᠭᠡ ᠪᠢᠴᠢᠭ᠌ ᠮᠠᠲ᠋ᠧᠷᠢᠶᠠᠯ ᠪᠣᠯᠣᠨ ᠵᠠᠷᠯᠢᠭ ᠠᠴᠠ ᠪᠢᠴᠢᠭᠰᠡᠨ ᠨᠢᠭᠡ ᠮᠠᠲᠧᠷᠢᠶᠠᠯ ᠨᠢ ᠠᠳᠠᠯᠢᠬᠠᠨ ᠪᠢᠴᠢᠭ᠌ ᠮᠠᠲᠧᠷᠢᠶᠠᠯ ᠪᠣᠯᠣᠨ᠎ᠠ ᠂ ᠬᠡᠷᠡᠭᠯᠡᠭᠡᠨ ᠦ AI ᠬᠠᠪᠲᠠᠰᠤ ᠶᠢᠨ ᠳᠠᠮᠵᠢᠭᠰᠠᠨ ᠪᠠᠶᠢᠴᠠᠭᠠᠯᠲᠠ ᠨᠢ ᠪᠠᠰᠠ ᠵᠠᠷᠯᠢᠭ ᠤᠨ ᠬᠠᠷᠢᠯᠴᠠᠭᠰᠠᠨ ᠴᠧᠺ ᠪᠣᠯᠣᠨ᠎ᠠ ᠃

## ᠵᠠᠰᠠᠪᠤᠷᠢᠯᠠᠬᠤ᠄ ᠪᠢᠴᠢᠭ᠌ ᠮᠠᠲ᠋ᠧᠷᠢᠶᠠᠯ᠂ ᠬᠠᠭᠤᠳᠠᠰᠤ᠂ᠳᠡᠯᠭᠡᠨ

## ᠡᠷᠢᠬᠦ ᠂ ᠵᠢᠷᠤᠭ ᠳᠦᠷᠰᠦ ᠪᠣᠯᠣᠨ ᠵᠠᠭᠤᠴᠢᠯᠠᠭᠤᠷ ᠵᠠᠷᠯᠢᠭ

`search`᠂ `image` ᠪᠠ `media` ᠨᠢ ᠪᠠᠰᠠ ᠪᠡᠯᠡᠳᠭᠡᠯ ▸ AI ▸ ᠦᠨᠳᠦᠷ ᠵᠡᠷᠭᠡ

- ᠶᠢᠨ ᠲᠤᠲᠤᠷᠠᠬᠢ ᠤᠭᠲᠤᠭᠳᠠᠭᠰᠠᠨ ᠶᠠᠭᠤᠮ᠎ᠠ ᠢᠢ ᠬᠡᠷᠡᠭᠯᠡᠨ᠎ᠡ᠃ `search` ᠦᠷᠬᠦᠯᠵᠢ ᠠᠵᠢᠯᠯᠠᠨ᠎ᠠ᠃ ᠲᠡᠷᠡ ᠪᠤᠯ ᠦᠷ ᠡ  ᠶᠢᠨ ᠦᠭᠡᠢ ᠡᠷᠢᠬᠦ  ᠢᠢ ᠬᠡᠷᠡᠭᠯᠡᠨ᠎ᠡ᠂ ᠡᠰᠡᠭᠦᠯ᠎ᠡ ᠰᠤᠩᠭ᠋ᠤᠭᠰᠠᠨ ᠲᠦᠯᠬᠢᠭᠦᠷ ᠨᠢ ᠲᠡᠭᠦᠨ ᠤ ᠡᠷᠢᠬᠦ ᠬᠠᠩᠭ᠋ᠠᠭᠴᠢ ᠶᠤᠮ᠃
- `image` ᠨᠢ ᠲᠠᠭᠠᠯᠠᠮᠵᠢ  ᠳᠡᠬᠢ ᠵᠢᠷᠤᠭ ᠳᠦᠷᠰᠦ ᠪᠦᠷᠢᠯᠳᠦᠬᠦ ᠰᠤᠩᠭ᠋ᠤᠯᠳᠠ  ᠢᠢ ᠬᠡᠷᠡᠭᠯᠡᠨ᠎ᠡ᠃ ᠲᠣᠭᠲᠠᠭᠰᠠᠨ ᠬᠤᠭᠤᠴᠠᠭᠠᠨ ᠤ ChatGPT ᠲᠦᠯᠦᠪᠯᠡᠭᠡ ᠪᠡᠷ (ᠺᠣᠳ᠋ ᠤᠨ ᠵᠢᠷᠤᠭ ᠤᠨ ᠵᠤᠷᠭ᠌ᠷᠠᠭ᠌) ᠢᠶᠠᠷ ᠵᠢᠷᠤᠵᠤ ᠂ ᠲᠠᠨ ᠤ ᠺᠣᠺᠲᠧᠺᠷᠦᠭᠴᠢ ᠪᠡᠷ ᠳᠠᠮᠵᠢᠨ ᠲᠠ ChatGPT ᠲᠦᠯᠦᠪᠯᠡᠭᠡ ᠪᠡᠷ ᠵᠢᠷᠤᠵᠤ ᠂ ᠭᠡᠪᠡᠴᠦ ᠵᠥᠪᠬᠡᠨ ᠲᠠᠨ ᠤ ᠠᠦᠢᠲ᠋ᠣᠲ᠋ ᠳᠠᠭᠤᠳᠠᠯᠭ᠎ᠠ ᠶᠢ ᠵᠥᠪᠰᠢᠶᠡᠷᠡᠭᠰᠡᠨ ( **off by default** ᠬᠠᠭᠠᠨ᠎ᠠ ᠂ [ᠶᠢ ᠦᠵᠡᠬᠦ](help://mcp) ᠃ ᠡᠰᠡ ᠲᠡᠶᠢᠮᠦ ᠪᠣᠯ ᠂ ᠴᠢᠨᠤ ᠲᠣᠬᠢᠷᠠᠭᠤᠯᠤᠭᠰᠠᠨ ᠵᠢᠷᠤᠭ ᠳᠦᠷᠰᠦ ᠶᠢᠨ ᠲᠥᠯᠥᠪᠦᠷᠢ ᠶᠢᠨ ᠲᠦᠯᠬᠢᠭᠦᠷ ᠢ ᠬᠡᠷᠡᠭᠯᠡᠨ᠎ᠡ ᠃ `--model` ᠶᠢ ᠲᠡᠷᠡ ᠵᠤᠷᠪᠤᠰ ᠵᠠᠮ ᠨᠢ ᠦᠶ᠎ᠡ ᠳᠦ ᠬᠡᠷᠡᠭᠯᠡᠨ᠎ᠡ ᠃ ᠦᠭᠡᠢ ᠪᠣᠯ ᠵᠠᠷᠯᠢᠭ ᠨᠢ ᠲᠠᠨ ᠤ ᠬᠡᠷᠡᠭᠯᠡᠵᠦ ᠪᠣᠯᠬᠤ ᠮᠣᠳᠧᠯ ᠢ ᠬᠠᠷᠢᠭᠤᠯᠨ᠎ᠠ ᠃ ᠵᠢᠷᠤᠭ ᠢ `--ref` ᠢᠶᠠᠷ ᠦᠭ᠍ᠭᠦᠭ᠍ᠰᠡᠨ ᠬᠣᠶᠠᠷ ᠵᠠᠮ ᠳᠡᠭᠡᠷ᠎ᠡ ᠪᠦᠷ ᠠᠵᠢᠯᠯᠠᠨ᠎ᠠ ᠃
- `media` on a picture uses a key provider when one is set up. It uses your Claude or Codex subscription only when you have allowed that, and that is **off by default** ; [Connecting a coding agent](help://mcp) explains the switch and its limits.
- `media` on video or audio needs a key provider that supports video.
