# Markdown засварлагч

Markdown засварлагч нь .md / .markdown - болон .txt / .json -г шууд эх харагдац руу нээдэг — эх сурвалж + үзүүлсэн-урьдчилан үзэх туршлагаар.

- **Нээлттэй** : Нүүр хуудас эсвэл Файлаас ▸ Нээлттэй; CLI бас ажилладаг.
- **Засварлах** : энгийн текст засварлах; GFM өргөтгөлүүд (хүснэгтүүд, даалгаврын жагсаалт, зураас, автомат холбоосууд) нь урьдчилан харах хэлбэрээр дүрслэгддэг.
- **Урьдчилан үзэх** : шууд; зураг гэх мэт харьцангуй хөрөнгийг баримт бичгийн хажууд шийддэг.
- **Хадгалах** : байт итгэлтэй — BOM, CRLF болон арын шинэ мөр байгаа эсэх нь хадгалагдана; өөрчлөгдөөгүй хадгалалт нь файлыг дахин бичихгүй.
- **Find & replace** : ctrl+F эх сурвалжийг хайдаг; Бүгдийг буцааж солих
- **AI** : урьдчилан тохируулсан товчлуурууд нь туслахад баримт бичгийг дахин бичих, өргөтгөх, орчуулах боломжийг олгоно. Сонголтыг AI-аас нууж болно (AI самбарын бүлгийг үзнэ үү).
- **Холбоосуудыг нээх** : засварлах явцад Ctrl+click холбоосыг (Mac дээр ⌘) хөтөч дээрээ нээх; энгийн товшилтоор курсорыг холбоосын текстэнд оруулснаар та үүнийг засах боломжтой болно. Үзүүлэнгийн горимд (F5) энгийн товшилтоор холбоос нээгдэнэ.

## Хэрэгслийн самбар

Засварлагчийн дээрх нэг эгнээний товчлуурууд (хэрэгслийн зөвлөгөө авахын тулд хулганыг гүйлгэнэ үү):

- **Файл ба түүх** : Хадгалах, Хадгалах, Буцаах, Дахин хийх, Хайх; Баруун талд байгаа **AutoSave** унтраалга нь дискэнд өөрчлөлтийг таймер дээр бичдэг.
- **AI товчлуур** : AI самбарыг нээнэ; Үүний хажууд дахин бичих / өргөтгөх / орчуулах урьдчилан тохируулгууд байдаг.
- **Догол мөрийн хэв маяг** (унадаг): үндсэн текст болон гарчгийн түвшний хооронд шилжих.
- **Inline форматлах** : **тод** , _italic_, ~~stricethrough~~, `inline code` , холбоос.
- **Жагсаалт** : сумтай, дугаарласан, ажлын жагсаалт.
- **Insert** : хүснэгт, зураг, хэвтээ дүрэм
- **Properties** : файлын дээд хэсэгт байрлах YAML-н урд талын блок руу орох буюу үсрэх.
- **тойм** : гарчгийн шатлалаар үсрэх.
- **Үг үсгийн алдаа шалгах** : энэ баримт бичгийн зөв бичгийн алдаа шалгахыг асаах/унтраах.
- **Зургийн хостын тохиргоо** : эхлээд буулгасан болон буулгасан зургуудыг өөрийн хадгалах сан руу илгээнэ үү — S3-тэй нийцтэй (R2/OSS/COS/MinIO), SM.MS эсвэл GitHub - нөөцийн нөөц болгон орон нутгийн өмчийн хуулбар.

Гурван хурдан жишээ:

- **Гарчиг** : курсорыг ▸ догол мөрний хэв маягийн унадаг ▸ "Гарчиг 1" мөрөнд тавь.
- **Хүснэгт** : **Хүснэгт оруулах** дээр дарна уу ▸ мөр/баганын тоог чирнэ үү ▸ нүднүүдэд бичнэ үү; Урьдчилан харах нь үүнийг шууд харуулна.
- **Даалгаврын жагсаалт** : цөөн хэдэн мөр сонгох ▸ **Даалгаврын жагсаалт** дээр товшино уу ▸ мөр бүр `- [ ]` болж, урьдчилан харах хэсэгт тэмдэглэгээний нүдээр харагдана.

## Экспорт хийж байна

Файлын цэс, бүгд дотоод, үр дүнг хаана оруулахыг асууж байна:

- **Word хэлбэрээр экспортлох…** болон **PDF хэлбэрээр экспортлох …** жинхэнэ .docx эсвэл .pdf бичих .
- **ODT хэлбэрээр экспортлох …** нь Word экспорттой ижил хөрвүүлэлтээр .odt (OpenDocument текст) бичдэг; Хэрэв замд ямар нэг зүйл өөрчлөгдсөн эсвэл унасан бол та жагсаалтыг хараад эхлээд баталгаажуулна уу.
- **HWP баримтаар экспортлох…** ижил хөрвүүлэлтээр Hangul баримт бичгийг ( .hwp эсвэл .hwpx ) бичдэг; Гарчиг, жагсаалт, хүснэгтүүд Хангулынх шиг ирдэг бөгөөд дараагийн хуудсанд урт хүснэгт үргэлжилнэ. Хэрэв ямар нэг зүйлийг шилжүүлэх боломжгүй бол та жагсаалтыг хараад эхлээд баталгаажуулна уу.
- **Зураг хэлбэрээр экспортлох...** нь таны сонгосон лавлах руу агуулгын элемент бүрт PNG бичдэг.
- **Докс руу хөрвүүлж, нээх** нь .docx руу хөрвүүлээд, үүнийг апп дотор суулгасан Docs tab-д нээдэг — энэ нь үүлэн доторх ямар нэгэн зүйлд шилжүүлэг биш бөгөөд хөрвүүлсэн хуулбар нь долоо хоногийн дараа цэвэрлэсэн кэш хавтсанд хадгалагдана.

## Эх сурвалжийг харах

Тууз нь **Эх сурвалж** унтраалгатай (апптай хамт локалчлагдсан). Үүнийг асаахад редакторыг түүхий Markdown-аар солих болно: яг хадгалсан бичвэр, ямар ч гоё зүйл байхгүй, таны доор ямар ч хэвийн зүйл байхгүй.

- **гар** : Ctrl+E (Mac дээрх ⌘E) нь эх сурвалжийг харах болон буулгасан засварлах зураг хооронд сэлгэдэг. Бүтэн дэлгэцээр уншихын тулд F5 дарна уу.
- **Засварлах нь байт найдвартай.** Эх сурвалжаас авсан хадгалалт нь засварлагчийн хадгалсантай ижил байт үүсгэдэг - BOM, CRLF болон арын шинэ мөр байгаа эсэх зэрэг нь бүгд хэвээр үлдэнэ.
- **Энэ нь ижил баримт бичиг юм.** чөлөөтэй нааш цааш сэлгэх; эх сурвалж нь редакторын өөрийнх нь бичвэр бөгөөд нэгтгэх ёстой хуулбар биш юм.
- **The formatting toolbar is unavailable** нээлттэй байхад тэдгээр товчлууруудын ихэнх нь засварлагчийн бүтцийг оруулдаг бөгөөд энэ нь зөвхөн дүрслэгдсэн талдаа ямар нэг зүйлийг илэрхийлдэг. Энэ нь харагдах байдлыг хаах үед буцаж ирдэг
- **.txt болон .json** энд шууд эх харагдацаар нээгдэнэ: үзүүлэх зүйл байхгүй тул эх сурвалж нь баримт бичиг юм.
