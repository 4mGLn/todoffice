# Фонт

## Фонтын жагсаалт

Фонтын удирдлага тус бүрийн редакторын Home дээр амьдардаг tab.

Тус бүрийн редакторын фонт сонгогч нэгддэг: орон нутгийн суусан фонтууд + платформ-д нийтлэг нэр дэвшигчид (ердийн Windows болон macOS гэр бүлүүд, Баруун болон CJK, орон нутгийн нэрийг багтаасан CJK фонтууд өөрийн үндсэн систем дээр тайлагнадаг). Систем орон нутгийн фонтуудыг жагсааж чадвал жагсаалт бодит байдлаар бүлэглэгддэг; үгүй бол бүх нийтлэг нэр дэвшигчийн жагсаалт руу шилжинэ.

Жагсаалтын бүх фонт энэ компьютер дээр суусан эсвэл програмтай хамт ирдэг. Юу ч татаж авдаггүй.

## Фонт файлыг суулгах (Slides)

- Slides фонтын жагсаалтын доод хэсэгт, **Фонт файлыг суулгах…** нь аль хэдийн байгаа фонт файлуудыг нэмдэг: .ttf, .otf, .ttc эсвэл .otc.
- Файлууд програмын өөрийн фонт хавтсанд хуулагддаг. Тэд зөвхөн энэ програмд ажиллана; системд юу ч суулдаггүй. Нээлттэй танилцуулгуудыг шинэ фонтоор дахин зохион байгуулна.
- Файлууд нэг фонтыг агуулж байгаа үед, үүнийг сонгосон зүйлдээ шууд хэрэглэнэ.
- Ингэж суулгасан фонт жагсаалтад гарахгүй. Дараа нь ашиглахын тулд, фонтын нэрийг фонтын хайрцагт оруулна уу.
- Нэг айлын хэд хэдэн жинг зэрэг суулгаж болно.
- Аппликейшнд ингэж суулгасан фонтыг устгах командыг өгөөгүй.

## Баримт бичигт шаардлагатай бөгөөд таныг байхгүй фонт

- Суулгаагүй фонтыг ашигласан баримт бичгийг орлуулагч фонтоор харуулна.

## CJK типографи

- Docs-д CJK фонт нь Word-тэй таарсан догол мөрийн шахалт болон kinsoku мөрийн дүрэмтэй байдаг (Docs бүлгийг үзнэ үү).
