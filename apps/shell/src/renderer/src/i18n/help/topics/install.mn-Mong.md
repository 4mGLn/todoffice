## Windows ᠳᠡᠭᠡᠷ᠎ᠡ

1. ᠬᠡᠪᠯᠡᠯ `TodOffice-Setup-<version>.exe` ᠶᠢᠨ ᠬᠠᠭᠤᠳᠠᠰᠤᠨ ᠠᠴᠠ ᠲᠠᠸᠠᠷ ᠢ ᠪᠠᠭᠤᠯᠭᠠᠨ᠎ᠠ
2. ᠵᠡᠭᠦᠯᠲᠡ ᠃ ᠤᠭᠰᠠᠷᠠᠭᠤᠷ ᠨᠢ ᠺᠣᠳ᠋ ᠤᠨ ᠲᠣᠭᠲᠠᠬᠤ ᠦᠭᠡᠢ ᠂ ᠡᠶᠢᠮᠦ ᠡᠴᠡ Windows ᠤᠷᠢᠳᠠᠪᠠᠷ ᠬᠦᠬᠡ ᠥᠩᠭᠡ ᠶᠢᠨ 《 ᠲᠠᠨ ᠤ Windows ᠺᠣᠮᠫᠢᠦ᠋ᠲ᠋ᠧᠷ ᠢ ᠬᠠᠮᠠᠭᠠᠯᠠᠨ᠎ᠠ 》 ᠴᠣᠩᠬᠣ ᠶᠢ ᠢᠯᠡᠷᠡᠭᠦᠯᠵᠦ ᠪᠣᠯᠣᠨ᠎ᠠ ᠃ **More info** ᠶᠢ ᠰᠤᠩᠭ᠋ᠤᠵᠤ **Run anyway** ᠃ ᠪᠣᠳᠠᠲᠠᠢ ᠦᠭᠡ ᠨᠢ ᠲᠠᠨ ᠤ Windows ᠦᠨ ᠳᠡᠪᠲᠡᠷ ᠢ ᠦᠵᠡᠨ᠎ᠡ
3. ᠤᠭᠰᠠᠷᠠᠭᠤᠷ ᠢ ᠳᠠᠭᠠᠭᠠᠳ ᠬᠠᠮᠤᠭ ᠡᠴᠦᠰ ᠲᠦ ᠲᠤᠯᠲᠠᠯ᠎ᠠ

ᠲᠡᠷᠡ TodOffice  ᠢᠢ ᠡᠬᠢᠯᠡᠬᠦ ᠲᠣᠪᠶᠣᠭ ᠲᠤ ᠬᠢᠬᠦ ᠶᠢᠨ ᠬᠠᠮᠲᠤ `.docx`᠂ `.xlsx`᠂ `.pptx`᠂ `.pdf` ᠪᠠ ᠨᠠᠢᠢᠵᠠ ᠢᠢ ᠳᠠᠩᠰᠠᠯᠠᠨ᠎ᠠ᠂ ᠡᠢᠢᠮᠦ ᠡᠴᠡ ᠨᠢᠭᠡ ᠮᠠᠲᠧᠷᠢᠶᠠᠯ ᠢ ᠬᠣᠶᠠᠷ ᠳᠠᠬᠢᠨ ᠳᠠᠷᠤᠪᠠᠯ ᠲᠡᠭᠦᠨ ᠢ ᠨᠡᠭᠡᠭᠡᠨ᠎ᠡ

ᠤᠴᠢᠷ ᠨᠢ ᠤᠭᠰᠠᠷᠠᠭᠴᠢ ᠨᠢ ᠭᠠᠷ ᠤᠨ ᠦᠰᠦᠭ ᠵᠢᠷᠤᠭᠰᠠᠨ ᠦᠭᠡᠢ᠂ ᠲᠠᠨ ᠤ ᠲᠠᠨ ᠤ ᠪᠠᠭᠤᠯᠭᠠᠭᠰᠠᠨ ᠬᠡᠪᠯᠡᠯ ᠤᠨ ᠨᠢᠭᠤᠷ ᠡᠴᠡ ᠪᠠᠭᠤᠯᠭᠠᠭᠰᠠᠨ ᠨᠢᠭᠡ ᠶᠢ ᠯᠡ ᠠᠵᠢᠯᠯᠠᠨ᠎ᠠ

## ᠪᠠᠭᠤᠯᠭᠠᠬᠤ Windows ᠪᠠᠨ ᠬᠠᠰᠢᠬᠤ ᠦᠶ᠎ᠡ ᠳᠦ

### Edge ᠪᠢᠴᠢᠭ᠌ ᠮᠠᠲ᠋ᠧᠷᠢᠶᠠᠯ ᠢ 《 ᠦᠷᠭᠦᠯᠵᠢ ᠪᠠᠭᠤᠯᠭᠠᠬᠤ ᠦᠭᠡᠢ 》 ᠭᠡᠵᠦ ᠬᠡᠯᠡᠵᠦ ᠪᠠᠢ᠌ᠨ᠎ᠠ

ᠮᠢᠺᠷᠣᠺᠤ ᠰᠸᠦᠭᠫᠢ ᠺᠤᠮᠫᠠᠨᠢ ᠳᠤ ᠢᠩᠭ᠍ᠢᠵᠦ ᠰᠡᠷᠡᠮᠵᠢᠯᠡᠭᠦᠯᠦᠭᠰᠡᠨ ᠨᠢ ᠲᠡᠭᠦᠨ ᠦ ᠣᠯᠠᠨ ᠬᠥᠮᠥᠨ ᠢ ᠲᠠᠲᠠᠵᠤ ᠭᠠᠷᠭᠠᠭᠠᠳᠤᠢ ᠮᠠᠲᠧᠷᠢᠶᠠᠯ ᠤᠨ ᠲᠤᠬᠠᠢ ᠰᠡᠷᠡᠮᠵᠢᠯᠡᠭᠦᠯᠵᠡᠢ ᠃ ᠪᠢᠴᠢᠺᠷᠣᠺ ᠤᠨ ᠹᠢᠯᠢᠮ ᠦᠨ ᠮᠠᠲ᠋ᠸᠷᠢᠶᠠᠯ ᠢ ᠬᠠᠳᠠᠭᠠᠯᠠᠬᠤ ᠵᠢᠭᠠᠪᠤᠷᠢ ᠪᠣᠯ

1. Edge ᠶᠢᠨ ᠪᠠᠭᠤᠯᠭᠠᠬᠤ ᠪᠥᠷᠢᠳᠬᠡᠯ （ **Ctrl+J** ） ᠂ ᠨᠡᠭᠡᠭᠡᠵᠦ ᠂ ᠁ ᠪᠢᠴᠢᠭ᠌ ᠮᠠᠲ᠋ᠧᠷᠢᠶᠠᠯ ᠤᠨ ᠬᠠᠵᠠᠭᠤ ᠳᠤ ᠂ **Keep**
2. ᠨᠡᠭᠡᠭᠡᠭ᠍ᠰᠡᠨ ᠴᠣᠩᠬᠣᠨ ᠳᠤ **Show more** ᠶᠢ ᠳᠠᠷᠤᠵᠤ **Keep anyway** ᠃ ᠮᠠᠲᠧᠷᠢᠶᠠᠯ ᠢ ᠲᠠᠨ ᠤ ᠪᠠᠭᠤᠯᠭᠠᠬᠤ ᠪᠢᠴᠢᠭ᠌ ᠦᠨ ᠳᠡᠪᠲᠡᠷ ᠲᠦ ᠦᠷᠭᠦᠯᠵᠢᠯᠡᠨ ᠪᠠᠢ᠌ᠨ᠎ᠠ

ᠲᠡᠷᠡ ᠴᠣᠩᠬᠣᠨ ᠳᠤ ᠪᠠᠰᠠ ᠨᠢᠭᠡ ᠹᠢᠼᠧᠯ ᠢ ᠠᠮᠤᠷ ᠲᠥᠪᠰᠢᠨ ᠭᠡᠵᠦ ᠮᠡᠳᠡᠭ᠍ᠳᠡᠳᠡᠭ᠍ ᠳᠠᠷᠤᠭᠤᠯ ᠪᠤᠢ ᠃ ᠲᠡᠷᠡ ᠵᠥᠪᠬᠡᠨ ᠮᠧᠺᠷᠣᠺᠷ ᠤᠨ ᠮᠡᠳᠡᠭᠦᠯᠦᠯᠲᠡ ᠶᠢᠨ ᠨᠢᠭᠤᠷ （ `feedback.smartscreen.microsoft.com` ） ᠶᠢ ᠯᠠ ᠨᠡᠭᠡᠭᠡᠵᠦ ᠂ ᠪᠢᠴᠢᠭ᠌ ᠮᠠᠲ᠋ᠧᠷᠢᠶᠠᠯ ᠢᠶᠠᠨ ᠬᠠᠳᠠᠭᠠᠯᠠᠳᠠᠭ ᠦᠭᠡᠢ ᠃ ᠲᠡᠷᠡ ᠨᠢᠭᠡ ᠨᠢᠭᠤᠷ ᠢ ᠬᠠᠭᠠᠭᠠᠳ ᠴᠣᠩᠬᠣᠨ ᠤ **Show more** ᠶᠢ ᠳᠠᠷᠤ

ᠴᠣᠩᠬᠣᠨ ᠳᠤ **Show more** ᠦᠭᠡᠢ ᠪᠤᠶᠤ **Keep anyway** ᠦᠭᠡᠢ ᠪᠣᠯ

- ᠣᠨᠳᠣᠣ ᠫᠷᠣᠭ᠍ᠷᠠᠮ ᠳᠤ ᠲᠠᠷᠬᠠᠭᠠᠬᠤ ᠬᠠᠭᠤᠳᠠᠰᠤᠨ ᠠᠴᠠ ᠲᠠᠨ ᠳᠤ ᠠᠳᠠᠯᠢ ᠹᠢᠯᠢᠮ ᠢ ᠭᠠᠷᠭᠠᠨ᠎ᠠ

## macOS ᠳᠡᠭᠡᠷ᠎ᠡ (beta)

ᠲᠠ 12 macOS ᠮᠧᠩᠲ᠋ᠧᠷᠢ ᠪᠤᠶᠤ ᠬᠣᠶᠢᠰᠢᠬᠢ ᠃ ᠮᠠᠺᠷᠧ ᠶᠢᠨ ᠢᠮᠡᠷ ᠳᠡᠭᠡᠷ᠎ᠡ Apple ᠨᠡᠭᠡᠭᠡᠭ᠍ᠴᠢ ᠶᠢᠨ ᠭᠠᠷ ᠤᠨ ᠦᠰᠦᠭ᠍ ᠪᠠᠶᠢᠬᠤ ᠦᠭᠡᠢ ᠂ ᠡᠶᠢᠮᠦ ᠡᠴᠡ ᠴᠢ ᠠᠩᠬ᠎ᠠ ᠤᠳᠠᠭ᠎ᠠ ᠨᠡᠭᠡᠭᠡᠬᠦ ᠳᠡᠭᠡᠨ macOS ᠨᠢ ᠡᠨᠡ ᠬᠦ ᠬᠠᠲᠠᠭᠤ ᠬᠡᠷᠡᠭᠰᠡᠯ ᠢ ᠵᠥᠭᠡᠯᠡᠨ ᠬᠡᠷᠡᠭᠰᠡᠯ ᠦᠭᠡᠢ ᠭᠡᠵᠦ ᠪᠠᠶᠢᠴᠠᠭᠠᠨ ᠰᠢᠯᠭᠠᠵᠤ ᠳᠡᠶᠢᠯᠬᠦ ᠦᠭᠡᠢ ᠭᠡᠰᠡᠨ ᠦᠭᠡ ᠬᠡᠯᠡᠵᠡᠢ ᠂ ᠪᠠᠰᠠ ᠨᠡᠭᠡᠭᠡᠵᠦ ᠥᠭ᠍ᠬᠦ ᠦᠭᠡᠢ ᠃ ᠨᠢᠭᠡ ᠤᠳᠠᠭ᠎ᠠ ᠵᠥᠪᠰᠢᠶᠡᠷᠡᠭᠡᠷᠡᠢ ᠂ ᠳᠣᠣᠷᠠᠬᠢ ᠮᠡᠲᠦ

1. ᠳᠮᠭ᠌ ᠢ ᠨᠡᠭᠡᠭᠡᠭᠡᠳ `TodOffice.app` ᠶᠢ **Applications** ᠶᠢᠨ ᠳᠡᠪᠲᠡᠷ ᠲᠦ
2. ᠬᠡᠷᠡᠭ᠍ᠯᠡᠭᠡᠨ ᠦ TodOffice ᠶᠢᠨ ᠳᠡᠪᠲᠡᠷ ᠡᠴᠡ ᠫᠷᠣᠵᠧᠺᠲ ᠢ ᠨᠡᠭᠡᠭᠡᠨ᠎ᠡ ᠃ ᠰᠡᠷᠡᠮᠵᠢ ᠭᠠᠷᠬᠤ ᠦᠶ᠎ᠡ ᠳᠦ ᠂ **Done** ᠢ ᠳᠠᠷᠤᠨ᠎ᠠ
3. **System Settings ▸ Privacy & Security** ᠢ ᠨᠡᠭᠡᠭᠡᠨ᠎ᠡ ᠃ ᠳᠣᠣᠷ᠎ᠠ ᠲᠠᠯ᠎ᠠ ᠶᠢᠨ ᠣᠢ᠌ᠷᠠᠮ ᠳᠤ ᠂ TodOffice ᠨᠢ ᠲᠦᠭᠵᠢᠷᠯᠡᠭ᠍ᠳᠡᠭ᠍ᠰᠡᠨ ᠭᠡᠵᠦ ᠬᠡᠯᠡᠭ᠍ᠰᠡᠨ ᠮᠥᠷ ᠦᠨ ᠬᠠᠵᠠᠭᠤ ᠳᠤ **Open Anyway** ᠶᠢ ᠳᠠᠷᠤᠵᠤ ᠂ ᠴᠢᠨᠦ Mac enter ᠨᠢᠭᠤᠴᠠ ᠲᠡᠮᠳᠡᠭ᠌ ᠃ ᠴᠢᠨᠦ ᠡᠨᠡ ᠫᠷᠣᠭᠷᠠᠮ ᠢ ᠨᠡᠭᠡᠭᠡᠬᠦ ᠪᠡᠷ ᠲᠤᠷᠰᠢᠭᠰᠠᠨ ᠦᠶ᠎ᠡ ᠳᠦ ᠳᠠᠷᠤᠭᠤᠯ ᠳᠤ ᠢᠯᠡᠷᠡᠬᠦ ᠨᠢᠭᠡ ᠴᠠᠭ
4. ᠳᠠᠬᠢᠭᠠᠳ ᠦᠵᠡᠭ᠍ᠳᠡᠭ᠍ᠰᠡᠨ ᠴᠣᠩᠬᠣᠨ ᠳᠤ **Open** ᠃ ᠡᠭᠦᠨ ᠡᠴᠡ ᠬᠣᠢ᠌ᠰᠢ ᠲᠡᠷᠡ ᠰᠡᠷᠡᠮᠵᠢ ᠶᠢᠨ ᠦᠭᠡ ᠦᠭᠡᠢ ᠪᠡᠷ ᠨᠡᠭᠡᠭᠡᠭ᠍ᠳᠡᠨ᠎ᠡ

ᠠᠷᠪᠠᠨ ᠬᠣᠶᠠᠷ macOS ᠤᠨ ᠡᠳᠦᠷ ᠲᠦ ᠲᠡᠨᠳᠡ **System Preferences ▸ Security & Privacy ▸ General** ᠲᠣᠪᠴᠢ ᠶᠢ ᠨᠢ **Open Anyway**

ᠬᠡᠷᠪᠡ macOS ᠨᠢ ᠵᠣᠭᠰᠤ ᠶᠢ ᠡᠪᠳᠡᠷᠡᠵᠡᠢ ᠭᠡᠵᠦ ᠬᠡᠯᠡᠪᠡᠯ ᠂ ᠠᠯᠪᠠᠨ ᠤ ᠬᠡᠪᠯᠡᠯ ᠦᠨ ᠨᠢᠭᠤᠷ ᠠᠴᠠ ᠳᠠᠬᠢᠨ ᠪᠠᠭᠤᠯᠭᠠᠬᠤ ᠃ ᠤᠭᠰᠠᠷᠠᠭᠤᠯᠤᠭᠴᠢ SHA-256 ᡁᠫᠢᠺ ᠦᠨ ᠴᠠᠭ᠎ᠠ ᠶᠢ release ᠭᠠᠷᠭᠠᠭᠰᠠᠨ ᡁᠫᠢᠺ ᠲᠡᠮᠳᠡᠭ᠍ᠯᠡᠯ ᠦᠨ ᠮᠠᠲ᠋ᠧᠷᠢᠶᠠᠯ ᠢ ᠬᠠᠷᠢᠴᠠᠭᠤᠯᠵᠤ ᠦᠵᠡ ᠃ Mac ᠳᠡᠭᠡᠷ᠎ᠡ ᠦᠵᠦᠭᠦᠷ ᠦᠨ ᠦᠵᠦᠭᠦᠷ ᠲᠦ ᡁᠺᠫᠢᠶᠣᠤ ᠶᠢᠨ ᠴᠠᠭ᠎ᠠ ᠶᠢ ᠳᠠᠷᠤᠮᠯᠠᠵᠤ ᠪᠣᠯᠣᠨ᠎ᠠ
