- **ᠬᠡᠷᠡᠭᠯᠡᠬᠦ ᠵᠢᠭᠠᠪᠤᠷᠢ** ᠄ ᠡᠨᠡ ᠭᠠᠷ ᠳᠡᠪᠲᠡᠷ ᠢ ᠨᠡᠭᠡᠭᠡᠨ᠎ᠡ᠃
