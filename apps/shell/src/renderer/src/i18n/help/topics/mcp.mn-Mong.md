# ᠺᠣᠳ ᠤᠨ ᠠᠭᠧᠨᠲ ᠬᠣᠯᠪᠣᠬᠤ

GenOffice ᠨᠢ ᠵᠠᠭᠪᠤᠷ ᠤᠨ ᠪᠠᠶᠢᠷᠢᠰᠢᠯ ᠤᠨ ᠬᠡᠯᠡᠯᠴᠡᠭᠡᠷ ᠢ ᠶᠠᠷᠢᠵᠤ ᠪᠠᠶᠢᠨ᠎ᠠ ᠂ ᠡᠶᠢᠮᠦ ᠡᠴᠡ ᠨᠢᠭᠡ ᠺᠣᠳ᠋ᠯᠠᠭᠴᠢ ᠨᠢ ᠶᠠᠭ app ᠬᠡᠷᠡᠭᠯᠡᠵᠦ ᠪᠠᠢ᠌ᠭ᠎ᠠ ᠠᠳᠠᠯᠢ ᠬᠦᠳᠡᠯᠭᠡᠨ ᠦ ᠬᠥᠳᠡᠯᠭᠡᠭᠦᠷ ᠮᠠᠰᠢᠨ ᠢᠶᠠᠷ ᠲᠠᠨ ᠤ ᠪᠢᠴᠢᠭ᠌ ᠮᠠᠲ᠋ᠧᠷᠢᠶᠠᠯ ᠢ ᠤᠩᠰᠢᠵᠤ ᠪᠢᠴᠢᠵᠦ ᠂ ᠪᠢᠴᠢᠵᠦ ᠭᠠᠷᠭᠠᠨ᠎ᠠ ᠃ ᠨᠠᠢ᠌ᠷᠠᠭᠤᠯᠤᠯᠲᠠ ᠨᠢ ᠹᠢᠼᠧᠮ ᠦᠨ ᠲᠥᠷᠮ᠎ᠡ ᠶᠢ ᠲᠠᠭᠠᠮᠠᠭᠯᠠᠵᠤ ᠪᠠᠶᠢᠬᠤ ᠪᠢᠰᠢ ᠄ ᠲᠡᠷᠡ ᠨᠢ ᠭᠦᠢᠴᠡᠳᠬᠡᠭᠴᠢ ᠶᠢᠨ ᠠᠳᠠᠯᠢ ᠨᠢᠭᠡ ᠲᠣᠮᠢᠶᠠᠯᠠᠯ ᠤᠨ ᠳᠣᠲᠣᠷ᠎ᠠ ᠠᠴᠠ ᠦᠰᠦᠭ᠍ ᠴᠣᠬᠢᠭᠰᠠᠨ OP ᠦᠯᠢᠭᠡᠷ ᠢ ᠭᠠᠷᠭᠠᠨ᠎ᠠ ᠃

## ᠬᠡᠷᠡᠭᠯᠡᠭᠡᠨ ᠦ

ᠡᠴᠡ ᠳᠠᠩᠰᠠᠯᠠᠨ᠎ᠠ ᠃ **▸ ᠨᠡᠶᠢᠯᠡᠭᠦᠯᠦᠯᠲᠡ** ᠡᠨᠡ ᠤᠴᠢᠷ ᠢ ᠬᠢᠵᠦ ᠪᠣᠯᠣᠨ᠎ᠠ ᠃ ᠡᠨᠡ ᠬᠠᠪᠲᠠᠰᠤ ᠶᠢᠨ ᠬᠣᠶᠠᠷ ᠬᠠᠭᠠᠰ ᠲᠤᠰᠠ ᠲᠠᠢ ᠂ ᠲᠠ ᠠᠯᠢ ᠨᠢᠭᠡ ᠪᠤᠶᠤ ᠬᠣᠶᠠᠷ ᠵᠦᠢᠯ ᠢ ᠪᠦᠷ ᠬᠡᠷᠡᠭᠯᠡᠵᠦ ᠪᠣᠯᠣᠨ᠎ᠠ ᠃

**The skill.** ᠡᠨᠡ ᠮᠠᠰᠢᠨ ᠳᠤ ᠭᠠᠷᠳᠠᠭ ᠺᠣᠳ᠋ ᠤᠨ ᠡᠮᠴᠢ ᠪᠦᠷᠢ ᠶᠢᠨ ᠨᠢᠭᠡ ᠮᠥᠷ — Claude Code ᠂ `~/.agents` ( Codex ᠂ ᠮᠥᠷᠥ ᠂ Gemini CLI ᠂ ᠺᠯᠢ ᠂ ᠨᠣᠮᠧᠷ ᠤᠨ ᠺᠯᠢ ᠪᠣᠯᠣᠨ Openᠺᠣᠳ᠋ ᠤᠩᠰᠢᠨ᠎ᠠ )᠂ ᠰᠠᠯᠬᠢᠨ ᠳᠠᠪᠠᠯᠭᠠᠨ — **Install** ᠂ **Update** ᠪᠣᠯᠣᠨ **Uninstall** ᠂ **Install into another folder…** ᠂ **Download skill (zip)** ᠪᠣᠯᠣᠨ **Copy path** ᠵᠡᠷᠭᠡ ᠃ ᠬᠡᠷᠪᠡ ᠲᠤᠰᠠᠯᠠᠭᠴᠢ ᠶᠢᠨ ᠨᠡᠷ᠎ᠡ ᠶᠢᠨ ᠵᠢᠩ ᠳᠦ ᠵᠢᠭᠰᠠᠭᠠᠭᠳᠠᠭᠰᠠᠨ ᠦᠭᠡᠢ ᠪᠣᠯ ᠲᠡᠭᠦᠨ ᠦ `SKILL.md` ᠶᠢ ᠤᠩᠰᠢᠵᠤ ᠪᠠᠢ᠌ᠭ᠎ᠠ ᠨᠢᠭᠡ ᠬᠠᠪᠳᠠᠰᠤ ᠶᠢ GenOffice ᠵᠢᠭᠠᠨ ᠂ ᠡᠰᠡᠭᠦᠯ᠎ᠡ ᠰᠢᠫᠢᠺ ᠢ ᠬᠠᠳᠠᠭᠠᠯᠠᠭᠠᠳ ᠲᠤᠰᠠᠯᠠᠭᠴᠢ ᠳᠤ ᠤᠭᠰᠠᠷᠠᠭᠤᠯᠤᠨ᠎ᠠ ᠃ ᠮᠡᠷᠭᠡᠵᠢᠯ ᠦᠨ ᠪᠣᠯᠣᠨ MCP ᠵᠡᠷᠭᠡ ᠨᠢ ᠬᠠᠮᠲᠤ ᠰᠠᠭᠤᠵᠤ ᠪᠣᠯᠣᠨ᠎ᠠ ᠄ ᠬᠠᠪᠰᠤᠷᠤᠭᠴᠢ ᠨᠢᠭᠡ ᠶᠢ ᠰᠤᠩᠭ᠋ᠤᠵᠤ ᠂ ᠲᠡᠳᠡᠨ ᠦ ᠬᠣᠶᠠᠷ ᠪᠦᠷ ᠠᠳᠠᠯᠢᠬᠠᠨ ᠤᠴᠢᠷ ᠶᠠᠪᠤᠳᠠᠯ ᠢ ᠬᠢᠵᠦ ᠪᠣᠯᠣᠨ᠎ᠠ ᠃ ᠡᠷᠲᠡᠬᠡᠨ ᠲᠡᠷᠡ ᠲᠠᠪᠤᠨ ᠪᠠᠭᠠᠵᠢ ᠶᠢᠨ ᠨᠢᠭᠡ ᠬᠠᠪᠳᠠᠰᠤ ᠳᠤ ᠤᠭᠰᠠᠷᠠᠭᠰᠠᠨ ᠬᠠᠭᠤᠯᠪᠤᠷᠢᠯᠠᠯᠲᠠ ᠶᠢ ᠬᠠᠮᠲᠤ ᠬᠡᠷᠡᠭᠯᠡᠳᠡᠭ ᠵᠢᠭᠰᠠᠭᠠᠯ ᠤᠨ ᠳᠣᠣᠷ᠎ᠠ ᠵᠢᠭᠰᠠᠭᠠᠭᠰᠠᠨ ᠮᠥᠷᠲᠡᠭᠡᠨ ᠲᠠᠰᠤᠷᠠᠯᠲᠠ ᠦᠭᠡᠢ ᠰᠢᠨ᠎ᠡ᠃ ᠬᠠᠮᠲᠤ ᠪᠡᠷ ᠶᠠᠪᠤᠯᠴᠠᠬᠤ ᠳᠡᠪᠲᠡᠷ ᠨᠢ ᠮᠡᠷᠭᠡᠵᠢᠯ ᠢ ᠣᠯᠤᠭᠰᠠᠨ ᠤ ᠳᠠᠷᠠᠭ᠎ᠠ ᠂ ᠲᠡᠷᠡ ᠨᠢᠭᠡ ᠬᠠᠭᠤᠯᠪᠤᠷᠢᠯᠠᠯ ᠢ ᠠᠪᠴᠤ ᠬᠠᠶᠠᠵᠤ ᠪᠣᠯᠣᠨ᠎ᠠ

**MCP ᠃** ᠬᠣᠶᠠᠷ ᠵᠠᠮ ᠱᠣᠭᠤᠮ ᠢ ᠣᠯᠭᠣᠨ᠎ᠠ᠄ **ᠲᠤᠰᠠᠯᠠᠭᠴᠢ ( ᠲᠠᠨᠢᠯᠴᠠᠭᠤᠯᠤᠭᠰᠠᠨ)** ᠡᠴᠡ ᠡᠬᠢᠯᠡᠵᠦ ᠂ ᠲᠠ ᠳᠠᠢ᠌ᠴᠢᠨ ᠳᠡᠭᠡᠷ᠎ᠡ ᠢᠯᠡᠷᠡᠭᠦᠯᠦᠭᠰᠡᠨ ᠲᠣᠨᠣᠭᠯᠠᠯ ᠢᠶᠠᠨ ᠨᠡᠮᠡᠵᠦ ᠂ ᠲᠤᠰᠠᠯᠠᠭᠴᠢ ᠦᠢᠯᠡᠴᠢᠯᠡᠭᠡᠨ ᠦ ᠲᠤᠰ ᠪᠡᠶ᠎ᠡ ᠪᠡᠨ ᠡᠬᠢᠯᠡᠵᠦ ᠂ **Local HTTP** ᠦᠢᠯᠡᠴᠢᠯᠡᠭᠡᠨ ᠦ ᠂ ᠲᠡᠭᠦᠨ ᠢ ᠲᠠᠨ ᠳᠤ ᠠᠵᠢᠯᠯᠠᠭᠤᠯᠤᠨ᠎ᠠ ᠃ ᠠᠯᠢ ᠴᠤ ᠪᠣᠯᠣᠭᠰᠠᠨ ᠂ ᠲᠤᠰᠠᠯᠠᠭᠴᠢ GenOffice ᠲᠠᠢ ᠶᠠᠷᠢᠯᠴᠠᠨ᠎ᠠ ᠂ ᠭᠡᠪᠡᠴᠦ ᠴᠢ ᠯᠠᠪ ᠵᠠᠷᠯᠢᠭ ᠴᠣᠬᠢᠵᠤ ᠳᠡᠶᠢᠯᠬᠦ ᠦᠭᠡᠢ ᠃

## ᠵᠠᠷᠯᠢᠭ ᠤᠨ ᠬᠥᠰᠥᠨᠥᠭ᠍ ᠦᠨ

ᠦᠵᠦᠭᠦᠷ ᠦᠨ ᠨᠢᠭᠡ ᠦᠵᠦᠭᠦᠷ ᠦᠨ ᠠᠳᠠᠯᠢ ᠶᠠᠪᠤᠳᠠᠯ — ᠡᠨᠡ ᠪᠣᠯ ᠲᠡᠷᠢᠭᠦᠨ ᠦ ᠵᠠᠮ ᠮᠥᠨ ᠂ ᠮᠥᠷᠲᠡᠭᠡᠨ ᠨᠠᠢ᠌ᠳᠠᠪᠤᠷᠢ ᠶᠢᠨ ᠦᠢᠯᠡᠳᠬᠦᠨ ᠦ ᠬᠠᠪᠲᠠᠰᠤ ᠡᠷᠢᠵᠦ ᠣᠯᠬᠤ ᠦᠭᠡᠢ ᠨᠢᠭᠡ ᠭᠠᠵᠠᠷ ᠪᠠᠢ᠌ᠬᠤ ᠦᠶ᠎ᠡ ᠳᠦ ᠂

```sh
ieumoffice mcp install all
```

ᠲᠡᠷᠡ ᠡᠨᠡ ᠮᠠᠰᠢᠨ ᠤ ᠺᠣᠳ᠋ᠯᠠᠭᠴᠢ ᠶᠢᠨ ᠺᠣᠳ᠋ ᠤᠨ ᠣᠷᠣᠯᠠᠭᠴᠢ ᠶᠢ ᠡᠷᠢᠵᠦ ᠂ ᠰᠲ᠋ᠳᠢᠤ᠋ ᠦᠢᠯᠡᠴᠢᠯᠡᠭᠡᠨ ᠦ ᠣᠷᠣᠯᠭ᠎ᠠ ᠶᠢ ᠥᠪᠡᠷ ᠢᠶᠡᠨ ᠥᠪᠡᠷ ᠢᠶᠡᠨ ᠪᠦᠷᠢᠯᠳᠦᠭ᠍ᠰᠡᠨ ᠪᠦᠷᠢᠯᠳᠦᠴᠡ ᠳᠦ ᠪᠢᠴᠢᠵᠦ ᠂ ᠦᠯᠡᠳᠡᠭ᠍ᠰᠡᠨ ᠮᠠᠲᠧᠷᠢᠶᠠᠯ ᠢᠶᠠᠨ ᠲᠡᠭᠦᠨ ᠦ ᠡᠷᠢᠭ᠍ᠴᠢ ᠪᠡᠷ ᠦᠯᠡᠳᠡᠭᠡᠨ᠎ᠡ ᠃ ᠣᠷᠣᠯᠭ᠎ᠠ ᠨᠢ `ieumoffice` ᠃ Claude ᠺᠣᠳ᠋ ᠳᠤ ᠭᠠᠷ ᠢᠶᠠᠷ ᠢᠶᠠᠨ ᠬᠢᠭᠰᠡᠨ ᠪᠣᠯ ᠠᠳᠠᠯᠢᠬᠠᠨ ᠳᠠᠩᠰᠠᠯᠠᠯ ᠢ `claude mcp add --transport stdio ieumoffice -- ieumoffice mcp` ᠃

```sh
ieumoffice mcp list             # where each agent stands
ieumoffice mcp install cursor    # just one
ieumoffice mcp uninstall cursor  # take it back out
```

ᠴᠢ ᠶᠠᠮᠠᠷ ᠨᠢᠭᠡᠨ ᠭᠠᠵᠠᠷ ᠲᠥᠪᠯᠡᠭ᠍ᠰᠡᠨ ᠣᠷᠣᠯᠠᠭᠴᠢ `--dir <path>` ᠃ `--force` ᠨᠢ ᠲᠡᠨᠳᠡ ᠪᠠᠢ᠌ᠭᠰᠠᠨ ᠨᠢᠭᠡ ᠵᠦᠢᠯ ᠢ ᠳᠠᠬᠢᠨ ᠪᠢᠴᠢᠵᠦ ᠪᠠᠢ᠌ᠨ᠎ᠠ ᠃

`ieumoffice mcp --help` ᠶᠢᠨ ᠦᠢᠯᠡᠴᠢᠯᠡᠭᠡᠨ ᠦ ᠬᠡᠷᠡᠭ᠍ᠰᠡᠯ ᠦᠨ ᠠᠯᠢᠪᠠ ᠪᠥᠬᠥᠨ ᠢ ᠨᠢᠭᠡ ᠳᠡᠯᠭᠡᠴᠡᠨ ᠳᠡᠭᠡᠷ᠎ᠡ ᠲᠠᠯᠪᠢᠳᠠᠭ ᠄ ᠳᠠᠩᠰᠠᠯᠠᠬᠤ ᠂ ᠬᠦᠰᠦᠨᠦᠭ᠍ᠲᠦ ᠶᠢ ᠬᠠᠰᠤᠬᠤ ᠪᠠ ᠨᠠᠷᠢᠨ ᠬᠦᠰᠦᠨᠦᠭ᠍ᠲᠦ ᠂ HTTP ᠳᠡᠭᠡᠷ᠎ᠡ ᠦᠢᠯᠡᠴᠢᠯᠡᠭ᠍ᠰᠡᠨ ᠂ ᠬᠣᠶᠠᠷ ᠲᠡᠮᠳᠡᠭ᠍ᠯᠡᠯ ᠦᠨ ᠲᠤᠭ ᠢ ᠦᠢᠯᠡᠴᠢᠯᠡᠨ᠎ᠡ ᠃

## ᠲᠤᠰᠠᠯᠠᠭᠴᠢ

ᠦᠭᠡᠢ ᠃ ᠥᠭᠡᠷ᠎ᠡ ᠨᠢᠭᠡ ᠮᠠᠰᠢᠨ ᠤ ᠵᠣᠴᠢᠨ ᠤ ᠡᠷᠦᠬᠡ ᠳᠦ ᠪᠣᠯ ᠬᠠᠷᠢᠨ HTTP ᠳᠡᠭᠡᠷ᠎ᠡ ᠦᠢᠯᠡᠴᠢᠯᠡᠭᠡ ᠳᠦ ᠣᠷᠣᠯᠠᠭᠤᠯᠪᠠᠯ ᠄

```sh
ieumoffice mcp --http 8765 --token <secret>
```

`--host <addr>` ᠨᠢ ᠰᠣᠨᠤᠰᠬᠤ ᠭᠠᠵᠠᠷ ᠢᠶᠠᠨ ᠥᠭᠡᠷᠡᠴᠢᠯᠡᠨ᠎ᠡ ᠃ ᠠᠳᠠᠯᠢᠬᠠᠨ ᠵᠣᠴᠢᠨ ᠡᠷᠦᠬᠡ ᠳᠡᠭᠡᠨ ᠠᠳᠠᠯᠢᠬᠠᠨ ᠲᠡᠮᠳᠡᠭ᠍ ᠢᠶᠡᠨ ᠳᠠᠮᠵᠢᠭᠤᠯᠤᠨ᠎ᠠ ᠃

HTTP ᠮᠠᠲᠧᠷᠢᠶᠠᠯ ᠤᠨ ᠳᠡᠭᠡᠷ᠎ᠡ ᠪᠠᠰᠠ ᠶᠠᠪᠤᠨ᠎ᠠ ᠄ `PUT /files/<name>` ᠨᠢ ᠨᠢᠭᠡ ᠵᠦᠢᠯ ᠢ ᠳᠠᠮᠵᠢᠭᠤᠯᠵᠤ ᠶᠠᠪᠤᠨ᠎ᠠ ᠂ ᠮᠠᠰᠢᠨ ᠪᠠᠭᠠᠵᠢ ᠪᠦᠷᠢ ᠳᠦ ᠪᠦᠷ ᠨᠢᠭᠡ ᠵᠤᠷᠪᠤᠰ ᠵᠠᠮ ᠢ ᠣᠷᠣᠯᠠᠭᠤᠯᠵᠤ `http(s)` URL ᠂ ᠭᠠᠷᠭᠠᠯᠲᠠ ᠨᠢ ᠪᠠᠭᠤᠯᠭᠠᠬᠤ ᠬᠠᠶᠢᠭ ᠪᠣᠯᠵᠤ ᠢᠷᠡᠨ᠎ᠡ — ᠲᠡᠭᠦᠨ ᠢ ᠪᠠᠭ᠎ᠠ ᠬᠡᠮᠵᠢᠶᠡᠨ ᠳᠡᠭᠡᠷ᠎ᠡ ᠨᠢ ᠪᠠᠰᠠ ᠬᠠᠭᠤᠷᠮᠠᠭ ᠤᠨ ᠡᠬᠢ ᠪᠠᠶᠠᠯᠢᠭ ᠢᠶᠠᠷ ᠳᠠᠮᠵᠢᠨ᠎ᠠ ᠃ Ops ᠂ specs ᠪᠣᠯᠣᠨ ᠦᠨ᠎ᠡ ᠬᠠᠩᠰᠢ ᠨᠢ ᠠᠯᠢ ᠴᠤ ᠨᠢᠭᠡ ᠲᠠᠯ᠎ᠠ ᠪᠠᠷ ᠳᠠᠮᠵᠢᠨ᠎ᠠ ᠃

## The Local HTTP server panel

Under **Local HTTP server** the app can run the server itself instead of leaving it to the assistant: an enable switch, a **Port** field, a **Running / Not running** indicator, **Background generation** (write documents straight to a path without opening the UI), and the **Client configuration example** to copy into your client. Opening **Advanced** adds the two connection URLs — Streamable HTTP and the legacy SSE one — a **Health check** URL, and a **Logging** switch that records server and tool activity to a local file you can **Open** , **Refresh** or **Clear** from there. It listens on localhost only.
