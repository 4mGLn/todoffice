# Гарын товчлолууд

Редактор бүр өөрийн гэсэн түлхүүртэй байдаг бөгөөд тэдгээрийн цөөхөн нь л хаа сайгүй ажилладаг. Энэ хуудас нь macOS болон Windows / Linux хөвчийг зэрэгцүүлсэн програмаар бүлэглэсэн бүрэн жагсаалт юм

## Үүнийг эхлээд унш

**Almost nothing here is global.** Доорх гурван хандалтын товчлуурууд нь; Тэднээс хойшхи бүх зүйл таны өмнө байгаа програмд хамаарах бөгөөд табыг солих үед өөрчлөгддөг

| Үйлдэл                                                           | macOS | Windows / Linux |
| ---------------------------------------------------------------- | ----- | --------------- |
| Хэрэглэгчийн гарын авлагыг нээнэ үү - програмын хаана ч ажиллана | F1    | F1              |
| Туузыг буулгах / өргөтгөх - засварлагч бүр                       | ⌥⌘R   | Ctrl+F1         |
| Туузыг нягтруулах — Зөвхөн баримт бичиг                          | ⌥⌘K   | Ctrl+Alt+K      |
| Гарын товчлолын хуудсыг нээх — Зөвхөн Word                       | ⌘/    | Ctrl+/          |
| Тохиргоог нээх — Word-аас бусад tab бүр                          | ⌘,    | Ctrl+,          |

- **F1 opens this manual** , товчлолын хуудас биш. Энэ нь програмын цэсэнд багтдаг тул Word, Sheets, Slides, PDF эсвэл Home tab зэрэг программ дээр ажилладаг
- **The ribbon toggle is `Ctrl+F1`, or `⌥⌘R` on macOS.** `F1`-г нүцгэн дарахад юу ч хийхгүй — F1 нь гарын авлага бөгөөд туузны товчлуур нь үүнийг санаатайгаар хуваалцдаггүй. `Ctrl+F1` нь macOS дээр ч хүлээн зөвшөөрөгддөг ч `⌥⌘R` нь Mac-д зориулсан Office-ийн гол хэрэглээ юм
- **The Keyboard Shortcuts sheet is Word's alone** ( `⌘/` ). Энэ нь яг доорх Word хүснэгтийг жагсаасан болно. Өөр редактор байхгүй
- `⌘,` ихэнх Mac програмуудын нэгэн адил Тохиргоог нээнэ ( Windows болон Linux дээрх `Ctrl+,` ). Word tab дээр хөвч нь доод тэмдэгт хэвээр үлддэг тул Mac дээрх програмын цэснээс Тохиргоог, эсвэл Windows болон Linux дээрх Цэс (☰) ▸ Тохиргоог нээнэ үү

![Word's own Keyboard Shortcuts sheet: the action on the left, the chord on the right, grouped by File, Edit, Text, Paragraph, Insert, Review and View](img/word-shortcuts.png)

- `⌘O` , `⌘S` болон `⌘P` нь засварлагч бүрийн ард тусад нь хэрэгждэг бөгөөд тэдгээр нь яг адилхан ажилладаггүй. Word-ийн `⌘P` нь эхлээд хэвлэхийг урьдчилан харах боломжийг олгодог тул нэг хэвлэсэн хуудас нь дэлгэцийн нэг хуудастай тэнцэнэ; PDF нь PDF хэвлэх харилцах цонхыг нээнэ; Шийт болон слайдууд дахин өөрийн гэсэн онцлогтой болсон
- **The rest is per-application.** Үг tab идэвхтэй байх үед `⌘B` нь Word-ийн тод өнгөтэй байна. Слайд идэвхжсэн үед `⌘B` Слайдын Тод хэлбэртэй байх ба энэ цэс таны дассан цэс биш байна. Зөвхөн сонгосон зүйлээр эсвэл тодорхой самбарт залгах үед Үйлдлийн баганад ингэж бичдэг

## Илтгэлийн горим

- **Start** : Word дээрх F5, PDF, Mindmap, HTML болон Markdown. Хүснэгтэнд Ctrl+F5 (A1-ээс) эсвэл Shift+F5 (одоо байгаа нүднээс) ашиглана уу. HWP баримт бичигт Ctrl+F5 ашиглана уу (F5 нь хүснэгтийн нүднүүдийг сонгоно)
- **Other entry points** : Word дээр Ctrl+F5 болон Shift+F5 унших харагдацыг бүтэн дэлгэцгүйгээр нээх; PDF-д тэдгээр нь одоогийн хуудаснаас эхэлдэг; HTML-д тэдгээрийг tab дотор харуулдаг
- **End** : Esc эсвэл F5. F11 нь цонхны бүрэн дэлгэц бөгөөд баримт бичгийн харагдах байдлыг өөрчилдөггүй

## Конвенцууд

- macOS баганад танил тэмдэгтүүдийг ашигладаг: `⌘` Command, `⌥` Option, `⇧` Shift , `⌃` Control
- Windows / Linux багана нь тэдгээрийг дараах байдлаар илэрхийлдэг: `Ctrl` , `Alt` , `Shift`
- GenOffice хоёр платформ дээр үнэхээр өөр түлхүүр хэрэгтэй бол хүснэгтэд харуулав. Нийтлэг тохиолдлууд нь Find & Replace-д зориулсан `⌃H` (macOS нь нуух зориулалттай `⌘H`-г эзэмшдэг), Go To-д зориулсан `⌥⌘G`, Slides-ийн хаах товчлуур юм
- Зөвхөн сонголтоор ажилладаг хөвчийг өөрийн гэсэн багана гэхээсээ илүү Action баганад бичдэг тул хүснэгт нь гурван баганын өргөнтэй хэвээр байна

## Хуудас

GenOffice Sheets нь .xlsx ажлын номыг нээж хадгалдаг. Доорх товчлолуудын ихэнх нь хүснэгтийн программуудад түгээмэл хэрэглэгддэг тул ихэнх нь аль хэдийн танил болсон байх болно

> **Editing wins.** Таныг нүд засах эсвэл **formula bar**-д бичиж байх үед Sheets дээрх бараг бүх товчлолыг үл тоомсорлодог бөгөөд ингэснээр шивэх, тэмдэглэгээг зөөх болон Backspace нь текст засварлах ердийн утгыг хадгална. Түлхүүр юу ч хийхгүй юм шиг байвал засварын дунд байгаа эсэхээ шалгана уу: эхлээд Esc эсвэл Enter дээр дараад дахин оролдоно уу. Сонголт дээр ажилладаг командууд нь харилцах цонх нээлттэй байхад юу ч хийхгүй. Хэрэв хөвч нь энэ дүрмийн үл хамаарах зүйл бол хүснэгтэд үүнийг зааж өгсөн болно

Хоёр конвенци нь Sheets-д зориулагдсан. `⌘` болон `⌃` нь ижил хувиргагч үүр - хоёулаа платформ бүр дээр хүлээн зөвшөөрөгддөг тул `⌘1` болон `Ctrl+1` нь ижил хөвч юм. **An empty Windows / Linux cell means the chord exists on macOS only.**

`Ctrl+N,T` гэж бичсэн түлхүүр нь Ctrl+N дарж, суллаад дараа нь T дарна гэсэн үг. `F5 → S` нь F5-тэй нүдний блок сонгоод S товчийг дарна гэсэн үг. `Ctrl+1 … Ctrl+0` нь баримт бичгийн нэгээс арав дахь хэв маягийг илэрхийлнэ; `Ctrl+Alt+1 … Ctrl+Alt+0` ижил хэв маягийг хэрэглэнэ. Нүдний блокыг сонгох үед `Ctrl+Shift+S` (macOS `⇧⌘S` дээр) блокийн нийлбэр болно; өөр газар тэр түлхүүрийг шинэ нэрээр хадгалдаг

Хангул хэл дээрх шиг хулганаар давхар товшилтоор үг, гурав дахин товшилтоор догол мөрийг бүхэлд нь сонгох, хоёр удаа дарж чирвэл үг үгээр өргөтгөл хийнэ. Энэ нь таныг толгой, хөл, зүүлт тайлбарыг засах үед бас ажиллана. Нүдний блокыг ( `Ctrl+C` ) хуулах нь нүдний текст болон хүснэгтийг өөрөө хуулах тул үндсэн хэсэгт буулгахад дахин ижил хүснэгттэй болно. Өөр хүснэгтийн нүдэнд зөвхөн каретаар буулгавал "Буулгах нүд" харилцах цонх нээгдэнэ: тэр нүднээс дарж бичих (хүснэгтийн гадна байгаа нүднүүдийг хасна) эсвэл дээр, доор, зүүн эсвэл баруун тийш нүднүүдийг оруулна. Зургийн булангийн бариулыг чирэх нь түүний пропорцийг хадгалдаг; Та буланг чирж байхдаа `Shift`-г дарахад дүрс эсвэл текстийн хайрцаг хадгалагдана. Объектыг хөдөлгөхдөө хэвтээ эсвэл босоо шугам дээр байлгахын тулд `Shift` дээр дарж, зөөх эсвэл хэмжээг нь өөрчлөх үед `Esc` дээр дарж объектыг байгаа газарт нь буцаана. Сонгосон объектыг сумтай товчлуурууд нь 0.2 мм, `Shift` + сумны товчлуурууд нь 1 мм-ийн хэмжээг өөрчилнө. `Tab` болон `Shift+Tab` нь хуудасны дараагийн болон өмнөх объектыг сонгох, `Shift+PageUp` болон `Shift+PageDown` нь объектыг урд нь авчирч эсвэл ар тал руу нь илгээж, `Shift+Home` болон `Shift+End` объектын урд буюу ард нь байрлуулна. `G` болон `U` нь бүлэглэх болон задлах, `L` болон `C` нь объектын шинж чанаруудын мөр, бөглөх цонхыг нээж, `Ctrl+E` объектыг устгадаг. Бусдын доор байрлах объектыг сонгохын тулд `Alt` товчийг дараад товшино уу; Цаашид товших бүрт дараагийнхыг доош сонгоно. Зургийн буланг `Shift` барьснаар чирвэл зургийг масштабаар нь тайрч, `Ctrl` бариулсан объектыг чирвэл байрандаа үлдэж, хуулбарыг нь орхисон газартаа буулгана
