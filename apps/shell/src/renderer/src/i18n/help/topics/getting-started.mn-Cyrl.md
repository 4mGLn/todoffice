# Түргэн эхлэл

TodOffice бол таны компьютер дээр ажилладаг оффисын багц юм. Нэг цонхны табуудаар Docs (бичвэр), Sheets (хүснэгт), Slides (танилцуулга), PDF, Markdown болон энгийн текст, HTML, Hangul, оюуны зураглал зэрэг засварлагчийг ашиглана. Засварлагч бүр өөрийн форматын файлыг нээж, хадгална. Баримт засварлахад сүлжээ шаардахгүй, харин AI үйлчилгээнд сүлжээ хэрэгтэй. Оюуны зураглалын засварлагч FreeMind, Freeplane-ийн .mm файлыг шинэ зураглал болгон импортолж, .xmind хэлбэрээр хадгална.

## Цонхны бүтэц

Цонх гурван хэсэгтэй.

- **Табын мөр**. Нээлттэй файл бүр тусдаа табтай. Зүүн захын нүүр хуудасны таб үргэлж харагдана. Файлын нэрийг өөрчлөхдөө таб дээр давхар товшино.
- **Агуулгын хэсэг**. Сонгосон табын засварлагч эсвэл нүүр хуудас харагдана.
- **Цэсийн мөр**. macOS дээр системийн цэсийн мөрөнд, Windows болон Linux дээр цонхны дээд хэсэгт байрлана. File, Edit, View цэсийн агуулга идэвхтэй засварлагчаас хамаарна.

## Баримт үүсгэх

Дараах аргуудаас сонгоно.

- Нүүр хуудасны [Түргэн эхлэл](help://getting-started) хэсэгт шинээр үүсгэх картыг дарна. Тухайлбал AI Docs, AI Sheets эсвэл AI Slides.
- **File ▸ New** цэснээс Docs, Sheets, Slides, Markdown, HTML эсвэл PDF-ийг сонгоно. Docs-ийн товчлол нь ⌘N эсвэл Ctrl+N.
- Байгаа файлаа цонх руу чирж нээнэ. Хэрэв TodOffice тухайн форматын үндсэн апп бол файлын нэр дээр давхар товшиж бас нээж болно.

Шинэ баримт нэргүй нээгдэнэ. Анх хадгалах үед диск дээр файл үүснэ.

## Файл нээх

- **File ▸ Open** (⌘O эсвэл Ctrl+O) цэсээр системийн файл сонгох цонх нээнэ. Дэмждэг форматын жишээ нь .docx, .doc, .odt, .xlsx, .xls, .csv, .tsv, .pptx, .ppt, .pdf, .md, .html.
- Нүүр хуудасны **Recent** жагсаалтаас файлаа сонгоно.
- Терминалаас `todoffice <file>` тушаалаар бас нээж болно.

## ODT баримт

Hancom Office, LibreOffice зэрэг аппын хэрэглэдэг OpenDocument текстийн .odt файлыг Docs табаар нээнэ. .docx нээдэг бүх аргыг хэрэглэж болно. Шинэ Docs баримт .docx хэлбэрээр эхэлнэ.

- **Ажиллах боломжууд**. Бичвэр, тэмдэгт, догол мөрийн формат, хүснэгтийн мөр багана нэмэх, устгах, нүд нэгтгэх, хуваах, зураг, хуудасны толгой ба хөл, зүүлт тайлбар, төгсгөлийн тайлбар, хуудасны тохиргоо, хэсэг, жагсаалт, дугаарлалт, гарчгийн загвар, холбоос, хайх, солих, зөв бичих дүрэм шалгах, хэвлэх, PDF ба HTML экспорт болон AI засвар.
- **ODT-д идэвхгүй боломжууд**. Сэтгэгдэл, өөрчлөлт хянах, харьцуулах, усан тэмдэг, бэх, гарчгийн жагсаалт, тэгшитгэл, дүрс, бичвэрийн хайрцаг болон диаграм оруулах, багана, эшлэл ба ном зүй, тайлбар ба дотоод лавлагаа, хуудасны өнгө, нууц үг болон засварын хязгаарлалт, зөвхөн унших зөвлөмж, загварын фонт ба өнгө, тольдсон захын зай. Товчнууд саарал харагдана. Эдгээр боломжийг ашиглах бол .docx хэлбэрээр хадгална.
- **Хэвээр хадгалагдах агуулга**. Эх баримтын тэгшитгэл, диаграм, зургууд түгжээтэй зураг болж харагдана. Тэдгээрийг устгаж болох ч засах боломжгүй. Хүснэгтийн түгжээтэй нүд хэвээр байна. Оролдоогүй хэсгүүд өөрчлөгдөхгүй. Нууц үгээр хамгаалсан ODT нээхийн өмнө нууц үгийг нь арилгана.
- **Save As** цэс .docx болон .odt-ийг санал болгоно. Формат солихын өмнө өөрчлөгдөх эсвэл хасагдах зүйлсийг харуулж, дараа нь шинэ файлыг таб дээр нээнэ. Markdown болон HTML-ийг **Export as ODT…** цэсээр гаргаж болно.

## Хадгалах

- **Гараар хадгалах**. ⌘S, Ctrl+S, эсвэл **File ▸ Save / Save As**. Анх хадгалахдаа файлын нэр, байршлыг сонгоно.
- **Автоматаар хадгалах**. Засварлагч бүрийн тохиргоо болон аппын ерөнхий анхдагч тохиргоог дагана. Зөвхөн уншиж буй PDF-ийг автоматаар дахин бичихгүй. Шинэ баримтыг анх хадгалсны дараа автоматаар хадгалж эхэлнэ.
- Хадгалаагүй өөрчлөлттэй табыг хаахад хадгалах, хаях эсвэл буцах сонголт гарна.
- Бичихдээ түр файл үүсгээд бэлэн болмогц үндсэн файлын нэрээр солино. Цахилгаан тасарсан ч үндсэн файл дутуу бичигдэхээс ингэж хамгаална.

## Түгээмэл товчлол

| Үйлдэл                | macOS | Windows / Linux |
| --------------------- | ----- | --------------- |
| Шинэ баримт           | ⌘N    | Ctrl+N          |
| Нээх                  | ⌘O    | Ctrl+O          |
| Хадгалах              | ⌘S    | Ctrl+S          |
| Таб хаах              | ⌘W    | Ctrl+W          |
| Тусламж нээх          | F1    | F1              |
| Хэрэгслийн тууз эвхэх | ⌥⌘R   | Ctrl+F1         |

**Хэрэгслийн тууз эвхэх** үйлдэл бүх засварлагчид ажиллана. Табын мөр үлдэж, доорх командын хэсэг нуугдана. Идэвхтэй табыг дарж эвхэнэ. Эвхсэн үед дурын табыг дарж дахин дэлгэнэ. Таб дээр давхар товшиход мөн адил. Сонголтыг засварлагч тус бүрд санана. Docs-д **⌥⌘K** эсвэл Ctrl+Alt+K дарвал туузанд зөвхөн дүрс үлдэнэ. Энэ сонголтыг бас санана.

Засварлагч тус бүрийн товчлолыг холбогдох бүлгээс үзнэ. Docs дээр **⌘/** дарж товчлолын жагсаалтаас хайж болно.

## Option+Command товчлол

Word-д Option+Command нь баримтын бүтэц дотор шилжих үйлдлүүдэд зориулагддаг. TodOffice мөн адил хэрэглэнэ. Ихэнх нь Docs-д, хоёр нь Sheets-д ажиллана. Нэг товчлол бүх засварлагчид үйлчилнэ.

**Docs**

| macOS           | Үйлдэл                     | Windows / Linux    |
| --------------- | -------------------------- | ------------------ |
| ⌥⌘1 / ⌥⌘2 / ⌥⌘3 | 1, 2, 3-р түвшний гарчиг   | Ctrl+Alt+1 / 2 / 3 |
| ⌥⌘0             | Ердийн бичвэр              | Ctrl+Alt+0         |
| ⌥⌘M             | Догол мөрийн тохиргоо      | Ctrl+Alt+M         |
| ⌥⌘A             | Шинэ сэтгэгдэл             | Ctrl+Alt+A         |
| ⌥⌘F             | Зүүлт тайлбар оруулах      | Ctrl+Alt+F         |
| ⌥⌘E             | Төгсгөлийн тайлбар оруулах | Ctrl+Alt+D         |
| ⌥⌘G             | Тодорхой байрлал руу очих  | Ctrl+G             |

macOS дээр **⌥⌘D** нь Dock-ийг харуулж, нуудаг тул төгсгөлийн тайлбарт ⌥⌘E ашиглана. Windows, Linux дээр Ctrl+Alt+D хэрэглэнэ. Очих үйлдэлд Windows, Linux дээр Alt хэрэггүй.

**Sheets**, хүснэгт идэвхтэй үед

| macOS | Үйлдэл      | Windows / Linux |
| ----- | ----------- | --------------- |
| ⌥⌘0   | Гадна хүрээ | Ctrl+Shift+7    |
| ⌥⌘−   | Хүрээгүй    | Ctrl+Shift+−    |

Mac дээрх Excel-ийн **⌘⇧7** ба **⌥⌘0** ижил гадна хүрээ тавина. Windows, Linux дээр Ctrl+Shift товчлолыг ашиглана.

**⌥⌘0** нь Docs-д Ердийн загвар, Sheets-д Гадна хүрээ гэсэн үйлдэлтэй. Засварлагч тус бүрд өөр утгатай тул апп даяар үйлчлэх товчлол болгон ашиглах боломжгүй.

**Бүх засварлагч**. **⌥⌘R / Ctrl+F1** нь дээрхтэй адил хэрэгслийн туузыг эвхэнэ.

macOS дээр ⌥⌘D нь системийн товчлол хэвээр байна.
