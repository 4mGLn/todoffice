# Нүүр хуудас

Нүүр хуудас нь GenOffice-н эхлэл хуудас юм: зүүн талд навигацийн хажуугийн самбар, баруун талд файлын жагсаалт, хурдан үүсгэх картууд

## Хажуугийн навигаци

- **Recent** : таны саяхан нээсэн файлууд. Мөр бүрд хэзээ - өнөөдөр, өчигдөр, эсвэл огноо гэсэн тэмдэг дарагдсан байна
- **Starred** : таны одоор тэмдэглэсэн файлууд. Файлын мөрийг хулганаа аваад од дээр дарж нэмэх эсвэл хасах. ⋯ цэсийн **Move to group** нь одоор тэмдэглэсэн файлуудыг нэрлэсэн бүлгүүдэд ангилдаг; Одтой харагдац нь тэдгээрээр шүүгддэг
- **User Guide** : энэ гарын авлагыг нээнэ
- **Ask AI** : мэдлэгийн суурь самбар — одоор тэмдэглэсэн файлаасаа асуулт асууж, хариулт авах боломжтой (доороос харна уу)
- **Projects** : AI-ийн ажиллах боломжтой хавтаснууд (төслүүд). Төсөл үүсгэх эсвэл байгаа фолдерыг ашиглан заавар, санах ой, файл, чатыг удирдахын тулд нэгийг нээнэ үү. [ төслүүдийг](help://projects) харна уу
- **Folders** : **Add folder…**-ийн тусламжтайгаар хажуугийн самбарт нэмэх эсвэл файлын менежерээс чирэх сангууд. Тус бүр нь та нээх, дэд хавтас үүсгэх, нэрийг өөрчлөх, устгах боломжтой root болдог; Офлайн байгаа нь боломжгүй гэж харагдах бөгөөд жагсаалтаас хасагдах боломжтой. **New folder** өөр нэгийг хийдэг
- **The row at the bottom** : AI холбогдсон эсэх — **Connect AI** эсвэл холбогдсон захиалгын нэрийг харуулах ба Тохиргоог нээнэ

Энд хогийн сав байхгүй. Устгасан файлууд нь системийн хогийн сав руу ордог бөгөөд нэгийг нь сэргээх нь үйлдлийн системийн ажил юм

## Файлын жагсаалт

Мөр бүр нь дүрс, файлын нэр, өөрчлөх хугацаа болон бусад зүйлийг харуулдаг. Мөрний ⋯ цэс нь

- **Open** , болон **Reveal in folder**-г ашиглан файлын менежер дэх файлын байршлыг тогтооно уу
- **Copy path**.
- **Move to folder…** : фолдер сонгогчийг нээж, файлыг зөөж, очих газарт ийм нэртэй файл байгаа үед алгасах / дарж бичих / нэрийг өөрчлөх боломжийг олгодог
- **Rename** : дотортой, өргөтгөл автоматаар хадгалагдана
- **Star / Unstar** — дахин эхлүүлэх үед од хэвээр байх ба нэрийг нь өөрчлөх үед файлыг дагаж мөрддөг
- **Duplicate** : ижил фолдерт хуулбар үүсгэдэг
- **Delete** : файлыг системийн хогийн сав руу зөөдөг бөгөөд энэ нь бүрмөсөн устгагдахгүй
- **Remove from list** , дээд түвшний Сүүлийн харагдац, файлд хүрэлгүйгээр оруулгыг орхих

### Нэг дор хэд хэдэн файл

Сонголт үүсгэхийн тулд эгнээний нүдийг чагтална уу, эсвэл ⌘/ctrl - дарна уу; Толгойн нүд нь одоо жагсаасан бүх зүйлийг сонгох ба жагсаалтын дээрх мөр нь бүх багцад **Move to folder…** болон **Delete files**-р сонгогдсон хэд байгааг мэдээлдэг. Та мөн олон сонголтыг хажуугийн самбар дээрх хавтас руу чирж болно

## Хайх

Дээд талд байгаа хайлтын талбар нь нэг дор хоёр зүйлтэй таарч байна

- **File names** : нэрээр нь хурдан шүүнэ
- **File contents** : GenOffice нь таны файлуудыг арын дэвсгэр дээр индексжүүлдэг (docx / odt / xlsx / pptx / pdf доторх текст), мөн файлуудыг хайж олох. Хамрах хүрээ болон унтраалга нь хайлтын тохиргоонд шууд харагдана

## Түргэн эхлүүлэх картууд

Жагсаалтын дээрх картууд нь нэг алхамаар шинэ баримт бичгийг үүсгэдэг. Карт дээр дарснаар ийм төрлийн файл үүсгэж, засварлагчийг нь нээнэ - шууд бичиж эхлээрэй, эсвэл хиймэл оюун ухааны ноорог (редактор бүр туузандаа **AI button**, сонгох контекст цэсэнд **Ask AI** байдаг)

Шинэ файл нь хажуугийн мөрөнд сонгогдсон хавтсанд бууна; ямар ч сонголтгүйгээр энэ нь үндсэн хавтас руу очдог

Картуудыг нуух эсвэл дарааллыг нь өөрчлөхийн тулд Тохиргоо → Ерөнхий хэсэгт **New documents on Home**-г ашиглана уу. Таны унтраасан төрлөөс зөвхөн картууд болон Шинэ цэсүүд үлдэнэ; ийм төрлийн файлууд өмнөх шигээ нээлттэй хэвээр байна. Нүүр хуудас дээр ⌘N/Ctrl +N эхний төрлийг харуулсан хэвээр байна. Тохиргоо → Засварлагч болон AI хэсэгт засварлагчийг унтраах нь өөр: картууд болон цэсийн оруулгууд нь мөн адил ажиллах бөгөөд файлыг нь нээхэд эхлээд асуудаг

Карт бүр юу хийдэг вэ

- **AI Docs** ( .docx ): Docs засварлагч дахь хоосон текст баримт бичиг. Файл нь зөвхөн **first save** дээр диск рүү бичигдсэн; шинэ баримт бичгүүд AI самбарыг өргөжүүлсэн үед нээгдэнэ (хэрэв та үүнийг хүсэхгүй бол Тохиргоо → "AI самбар" дотроос Унтраах эсвэл Буулгасан гэснийг сонгоно уу)
- **AI Sheets** ( .xlsx ): Хүснэгт засварлагч дахь хоосон хүснэгт. Хадгалах хүртэл дискэн дээр ямар ч файл байхгүй - нэр нь эхний хадгалалтад зориулагдсан; AI-ийн эхний үеийн дараа файлын нэрийг агуулгынх нь дагуу автоматаар өөрчлөх боломжтой
- **AI Slides** ( .pptx ): Слайд засварлагч дахь хоосон танилцуулга
- **AI Markdown** ( .md ): Markdown засварлагч дахь хоосон Markdown баримт
- **AI HTML** ( .html ): HTML засварлагч дахь хоосон вэб хуудас
- **AI PDF** ( .pdf ): бусдаас ялгаатай — энэ нь **immediately** нь зорилтот хавтсанд жинхэнэ хоосон нэг хуудас PDF үүсгэж, ердийн файл болгон нээдэг (PDF засварлагч нь бодит файлууд дээр ажилладаг). Текст бичих, засварлах, нэмэхэд сайн; файлын нэрийг анх хадгалахад агуулгынх нь дагуу автоматаар өөрчлөх боломжтой
- **Open local files** : Word (.docx / .doc / .odt), Excel (.xlsx /.xlsm/ .xls / .csv / .tsv), PowerPoint (.pptx / .ppt), PDF , Markdown (.md /.markdown) болон вэб хуудсууд (.html /.htm) системийн файл сонгогч. Олон сонголт ажилладаг; файл бүр өөрийн гэсэн tab. Энгийн текст файлууд ( .txt , .json ) энд нээгддэг — тэд Markdown редакторын эх үүсвэр харагдацад ордог

> Зөвлөгөө: Файл ▸ Шинэ цэсний мөрөнд ижил баримт бичгийн төрлүүдийг үүсгэнэ (⌘N/Ctrl +N нь анхдагчаар текст баримт бичигт тохирно); файлыг цонх руу чирэхэд нээгдэнэ

## Мэдлэгийн сангаас асуугаарай

- Эхлээд star файлуудыг (аппликейшн уншсан ямар ч төрлийн файлууд); самбарын толгой нь корпусыг тоолж, хоосон мэдлэгийн сан нь star ямар нэгэн зүйлийг сонгохыг зөвлөдөг
- Хариултууд нь ирсэн файлуудыг иш татдаг; ишлэл дээр дарж файлыг засварлагчаар нээнэ үү
- Холбогдсон AI хэрэгтэй; [ захиалгын холболт](help://subscription)-г үзнэ үү. Харилцан яриа нь зөвхөн санах ойд хадгалагддаг - програмыг хааснаар дуусгах болно
- Оролтын доор төслөө сонгоод фолдерын файлуудыг хайж, унших ба чат нь тэр хавтсанд хадгалагдах тул та өөр засварлагч дээр үргэлжлүүлэх боломжтой. Төсөлгүйгээр чат нь дээр дурдсанчлан зөвхөн санах ойд амьдардаг
- Хайлт нь Home search гэх мэт локал файлын индекс дээр ажилладаг; алга болсон файлууд корпусаас чимээгүйхэн унав
- Бүлгүүд зөвхөн одоор тэмдэглэсэн жагсаалтыг зохион байгуулдаг - мэдлэгийн сан нь үргэлж одтой файл бүрийг хамардаг
