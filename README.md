# TodOffice

[Монгол](README.md) · [English](README.en.md) · [한국어](README.ko.md)

TodOffice бол монгол хэлээр баримт бичиж, засварлахад зориулан хөгжүүлж буй, компьютер дээр ажилладаг оффисын программ юм.

## Яагаад TodOffice-ийг хөгжүүлэх хэрэгтэй вэ?

Бидэнд хичээлийн даалгавар хийхдээ ч, ажил дээрээ тайлан бичихдээ ч эх хэлээрээ ашиглахад эвтэйхэн оффисын программ хэрэгтэй. Цэсээ монголоор уншиж, кирилээр бичиж, монгол бичгээр баримт бэлдэхдээ дээрээс доош бичдэг заншлаараа бичихийг хүсдэг.

Өмнөд Солонгосын ахлах сургуулийн нэгэн солонгос хэлний багш уншиж, бичих өдөр тутмын ажилдаа зориулсан программ бүтээхээр нээлттэй эхийн GenOffice-ийг өөрчилж эхэлсэн нь IeumOffice-ийн эхлэл байв. Энэ түүхээс бид Монголд өдөр бүр баримт бичдэг хүмүүс ч хэрэглэдэг программаа өөрийн хэл, бичгийн онцлогт тааруулан сайжруулж чадна гэж бодсон. [IeumOffice-ийг бүтээсэн учир (англиар)](docs/upstream-readme.en.md#why-it-was-made)

Монгол, Өмнөд Солонгосын харилцаа өргөжихийн хэрээр хоёр талын хэрэглэдэг баримт бичгийг нээж чаддаг байх нь улам чухал болж байна. Өмнөд Солонгосын төрийн байгууллагууд тайлан зэрэг баримт бичгийг HWP, HWPX форматаар ч нийтэлдэг. Тиймээс бид TodOffice-ийг IeumOffice-д суурилан хөгжүүлэхээр сонгосон. IeumOffice эдгээр форматыг дэмжиж, баримтыг өөрийн компьютер дээр засварлах, хиймэл оюунтай холбох боломжийг бүрдүүлсэн байв. Ингэснээр бид цэсийг монгол хэлээр ашиглах, кирил болон монгол бичгээр бичихэд илүү анхаарч чадсан. [Монгол, Өмнөд Солонгосын дээд хэмжээний уулзалтын мэдээлэл (солонгосоор)](https://www.mofa.go.kr/www/brd/m_29514/view.do?seq=98) · [HWP, HWPX форматаар нийтэлсэн төрийн тайлан (солонгосоор)](https://www.mois.go.kr/frt/bbs/type001/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000336&nttId=129238)

Монгол Улс хөгжихөд бидэнд хэрэгтэй программ, үйлчилгээгээ өөрсдөө бүтээж, сайжруулж сурсан туршлага чухал. TodOffice-оор бид өдөр тутам хэрэглэдэг нэг хэрэгслээс эхэлж байна. Хэзээ нэгэн өдөр нэг сурагч шинэ хуудас нээгээд анхны даалгавраа монгол бичгээр дээрээс доош бичиж суухыг харахсан.

## Суулгах

2026-11-26-ны байдлаар [GitHub Releases](https://github.com/4mGLn/todoffice/releases) хуудсанд анхны албан ёсны хувилбар хараахан гараагүй байна. Хувилбар гарсны дараа доорх тушаал хамгийн сүүлийн тогтвортой хувилбарыг олж, таны компьютерт таарах багцыг суулгана. Тохирох багц байхгүй бол суулгагч мэдэгдээд зогсоно.

**Linux (x64), macOS (Apple silicon, Intel)** — Терминалд ажиллуулна.

```sh
curl -fsSL https://github.com/4mGLn/todoffice/releases/latest/download/install.sh | sh
```

Linux дээр `~/.local/bin/todoffice-desktop` тушаалаар программыг нээнэ. macOS дээр программыг `~/Applications/TodOffice.app` замд суулгана.

**Windows (x64, ARM64)** — PowerShell дээр ажиллуулна.

```powershell
irm https://github.com/4mGLn/todoffice/releases/latest/download/install.ps1 | iex
```

## Монгол хэл, бичгийн дэмжлэг

2026-11-26-ны байдлаар кирил (`mn-Cyrl`) болон монгол бичгийн (`mn-Mong`) орчуулгыг **урьдчилсан хувилбараар** туршиж болно. Тусламжийн 27 сэдвийг хоёр бичгээр унших боломжтой. Эдгээр орчуулгыг эх хэлээрээ ярьдаг хүмүүсээр хянуулах шаардлагатай. Орчуулж амжаагүй цэс, дэлгэцийн тайлбар англиар харагдана.

- Монгол бичгийн горимд цэс босоо байрлана. Энэ горимд Docs засварлагч дээр шинээр нээсэн хоосон баримтын бичвэр дээрээс доош, багана нь зүүнээс баруун тийш үргэлжилнэ. Өмнө нь хадгалсан баримт бичих чиглэлээ хадгална. Docs дээр чиглэлийг гараар сонгож болно. Бусад файлын форматад босоо бичвэр засварлах боломж харилцан адилгүй.
- Нүүр хуудасны карт, цэсийн таб, тохиргооны талбарууд жигд хэмжээ, зайтай. B, I, U дүрс эгц байрлах бөгөөд хэрэгслийн самбарыг хумихад зөвхөн цэс сонгох зурвас үлдэнэ.
- Түгээмэл үйлдлийг монгол үгээр нэрлэж, зарим мэргэжлийн нэр томьёог англи дуудлагаар нь монгол бичгээр галигласан. Эдгээр шинэ нэр, галигийг монгол бичгийн мэдлэгтэй, эх хэлээрээ ярьдаг хүмүүсээр хянуулах шаардлагатай.
